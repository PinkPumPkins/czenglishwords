📋 功能句总结 · 留言三连：take / leave / send

替人记：Can I take a message?（我帮你捎口信好吗？） 自己留：Would you like to leave a message? 发出：send a message 发消息（微信时代高频）

👨‍👩‍👧 家长指导卡

家长配合：设一周“家庭留言板”，孩子每天用英语给家长留一条 message（贴冰箱上），家长回一句；周五清点谁留得多、谁的句子被回得最积极——家庭内部的 message 系统，就是电话英语的实战场。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 留言互递：各自写一条英文口信塞给对方转交“第三人”，收件人复述检验信息是否走样；② 方向快测：互考 take / leave / send 的主语是谁，6题计分；③ 全对一起打卡，复述走样的一方可发一条 voice message 当“补偿”。

📝 中考考点卡 · message

考点1　take a message（接话方）↔ leave a message（打话方）方向辨析
考点2　send sb a message ＝ send a message to sb 双表达
易错　message 与 massage 只差一个字母，义天壤；message 可数（a message / messages）

⚖️ 易混辨析卡 · 别再认错message
message ↔ massage
经典拼写陷阱：message 消息，massage 按摩
messagen. 消息：send a message
massagen. 按摩：a foot massage
take a message ↔ leave a message
take＝接话方帮记；leave＝打话方自己留
take a message我帮你捎：Can I take a message?
leave a message我留个话：I’d like to leave a message.
🔥 火眼金睛：单选：I’m not in. Please ______ a message on my desk.
“我不在，请留口信”是你（来话方）主动留下信息，用 leave a message；take a message 是接话方替别人记。

👪 陪读故事 + 思维导图 + 词源小知识

📖 微型故事《The Golden Record》

科普社放了一部纪录片：1977年，人类把两张金唱片挂上旅行者号探测器，里面装着55种语言的问候、一段心跳，还有中文的问候。社长安然问：“如果外星人收到这条 message，他们听得懂吗？” 没人答得上来。纪录片最后说：唱片将在星际空间漂十亿年。散场后安然在本子上写：我们发出的可能永远无人收听，但 message 的意义不在签收，而在“我们曾说”——人类曾对黑暗大喊一声你好，哪怕回音要等十亿年。

🧑‍🏫 自测提问卡：
• 细节题：What is on the Golden Record? Name at least two things.
• 推断题：Why does the writer say the meaning of the message is in “having said it” rather than in being received?
• 迁移题（开放）：If you could send one sentence to space as a message, what would it be? 用英语写下来

🗺️ 思维导图

┌── 核心 ── message n. 消息；信息（复数 messages） ├── 电话链 ── take a message 捎口信 · leave a message 留口信 · call back 回电 ├── 网络链 ── send a message · text message 短信 · voice message 语音 ├── 词根链 ── mittere 派送 → mission · missile └── 文化 ── 1977 旅行者号金唱片

🏛️ 词源故事

message 经古法语来自拉丁语 missaticum，词根 mittere（派、送）。这个动词是拉丁语里最能“出差”的一个：mission（使命，被派出去的任务）、missile（导弹，被扔出去的东西）、admit（准许进入）、transmit（传送）全是它的后代。所以 message 的本质不是“字”，是“被送出去的东西”——口信短信皆然。

📜 名言 & 谚语

The medium is the message. — Marshall McLuhan《Understanding Media》1964（媒介即讯息——传播学最著名的判断）

🎵 歌词里的message

🎵 The Police《Message in a Bottle》(1979)：“Sending out an S.O.S.”——漂流瓶里的求救信唱上全球榜首，message 一旦被送出，就在寻找它的收件人。（歌名含message）
