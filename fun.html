1️⃣ 五维拆解法

形·拼写fun 只有三个字母，全短促音，词尾 n 别吞掉
✏️ 不可数名词：have fun ✓，❌ have a fun / ❌ funs
音·发音/fʌn/ 短元音 /ʌ/——与 fan /fæn/ 的 /æ/ 是经典最小对立对
🎧 跟读：have fun · What fun! · a fun day
意·释义n. 乐趣；快乐 adj. 有趣的——一个"双面词"：名词不可数，形容词随便用
用·句型① What is fun in a yard? ② We sit in the sun and have fun. ③ It’s fun to count ducks.
拓·同族have fun doing sth 做某事很开心 · for fun 为了好玩 · make fun of 取笑（贬义）· funny adj. 好笑的（必考辨析）

📋 功能句总结 · have fun + What is fun...?

问：What is fun in a yard? 答：Watching the animals is fun. / Sitting in the sun is fun. 祝愿：Have fun (doing sth)! 玩得开心！ 句型：It’s fun to do sth. 做某事很有趣

👨‍👩‍👧 家长指导卡

家长配合：把"今天学了什么"换成"今天什么最 fun"——晚饭时全家轮流说一件 fun 事，说不出的讲个笑话凑数；听写盯 fun / funny 的区分和 have fun 后接 doing。周末陪孩子去一次公园或菜场，用英语找三件 fun 的东西——你会发现，孩子的"乐趣清单"比成绩单更值得读。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① fun vs funny 裁判赛：互相出5句（The game is fun/funny.），判断正误并说理由，对3题过关；② 仿句接龙：轮流说 What is fun in...?（地点不许重复），接不上的做5个开合跳；③ 全部完成一起打卡，输的一方明天课间表演一个 funny face（不许 make fun of 同学）。

📝 中考考点卡 · fun

考点1　fun 不可数：have fun / great fun（❌ have a fun / ❌ funs）
考点2　have fun doing sth：We had fun counting ducks.
易错　fun（乐趣、有趣）≠ funny（好笑的、滑稽的）：The game is fun. / The story is funny.；make fun of 是贬义"取笑"

⚖️ 易混辨析卡 · 别再认错fun
fun ↔ funny
名词义与形容词义的错位——初中最高频辨析之一
funn. 乐趣；adj. 有趣的：The game is fun. 我们玩得开心
funnyadj. 好笑的：The story is funny. 让人发笑
have fun ↔ make fun of
一字之差，善意与恶意
have fun玩得开心：Have fun at the party!
make fun of取笑（不礼貌）：Don’t make fun of others.
🔥 火眼金睛：单选：We had great ______ on the farm.
fun 是不可数名词，great fun 是固定搭配；funny 是形容词"好笑的"；a fun 语法错误。

📖 微型故事《The Farm That Beat the Amusement Park》

研学去农场，方原一路都在抱怨：又不是游乐园，能有什么 fun？分组喂兔子时他躲得最远，直到一只大鹅叼走他的草帽，全组笑倒，追了三圈才夺回来。中午他蹲在篱笆边数鸭子，数到第十四只时发现那只一直在潜水——原来它在跟他玩捉迷藏。回程大巴上有人问游乐园和农场哪个好玩，方原想都没想：当然是这儿。他在研学手册最后一页写：Fun isn’t where you go; it’s how you look. 乐趣不在你去哪儿，而在你怎样去看。

🧑‍🏫 自测提问卡：
• 细节题：What two things on the farm made Fang Yuan laugh?
• 推断题：Why did his opinion change from "boring" to "the best"? 找出两处证据
• 迁移题（开放）：用英语写两句：What is fun in your school life? 并说明为什么

🏛️ 词源故事

fun 的祖先中古英语 fon，本义是"愚弄、捉弄"——16世纪前说某人有 fun 简直是骂人！直到17世纪，它才从"戏弄"洗白成"快乐的消遣"。今天 make fun of（取笑）里还封存着它最早的味道。所以这个词自带分寸感：一起玩是 fun，把快乐建在别人的难堪上，就成了 make fun of。

⚡ 冷知识

🔤 "a fun day" 这种用法在20世纪中期还被老派语法书判为错误——fun 只能当名词！但用它的人实在太多，如今主流词典已正式收录 fun 的形容词用法。一个词的"转正"，靠的是千万人天天用。
