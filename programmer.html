1️⃣ 五维拆解法

形·拼写program + mer → programmer：双写 m 再加 -er（重读闭音节规则）
✏️ 拼写陷阱：programmer 两个 m；program 一个 m
音·发音/ˈprəʊɡræmə(r)/ 重音在首音节；-er 弱读 /ə(r)/
🎧 跟读：a programmer · started out as programmers（课本原句）
意·释义n. 程序设计员；程序员——program（编程）+ er（做这件事的人）
用·句型① started out as programmers 从程序员起家（课本原句）② a computer programmer ③ He started programming when he was ten.
拓·同族program v. 编程 / n. 程序；节目单 · programming n. 编程

📋 功能句总结 · 职业词 -er 家族

program → programmer（编程的人） teach → teacher · sing → singer · win → winner（重读闭音节双写 n） 句型：He started out as… 他以……起家（课本原句）

👨‍👩‍👧 家长指导卡

📝 中考考点卡 · programmer

考点1　拼写双写：program → programmer（重读闭音节 + m）
考点2　职业后缀 -er：programmer / teacher / winner（winner 双写 n 对照）
易错　program n. 还可指“节目单；课程”；英式英语有时拼作 programme

⚖️ 易混辨析卡 · 别再认错programmer
program ↔ programmer
动作与人：program 编程，programmer 程序员
programv./n.：write a program
programmern. 人：a great programmer
program ↔ project
形近词：程序 ↔ 项目
programn. 程序；节目单：write a program
projectn. 项目；作业：do a school project
🔥 火眼金睛：选词填空：Lin wants to be a ______ and make his own apps.
职业名词 programmer＝program＋mer；program 是程序本身。

📖 微型故事《One Bug Away》

编程社招新考题只有一个：写个小程序让屏幕上的小猫跳过水坑。我调试到深夜，小猫总在水坑前摔下去——第十一次还是第十二次，记不清了。我想起课本里那句话：那些商人 started out as programmers，谁不是从 bug 里爬出来的？于是把报错一行行抄下来排查，终于在凌晨发现：一个分号写成了中文。改完那一刻，小猫稳稳落地。我盯着屏幕笑了：Every bug is a step, if you fix it. 每个 bug，修好就是台阶。

🧑‍🏫 自测提问卡：
• 细节题：What was the test task of the coding club?
• 推断题：Why did the writer copy down the error messages one by one?
• 迁移题（开放）：用英语描述你曾经“卡住又解决”的一次经历

🏛️ 词源故事

program 一路从希腊语 prographein（预先写下）走来：pro-（提前）+ graphein（写）。古希腊人用它指“公开的书面公告”；19世纪计算机时代，它成了“给机器预先写下的指令”。所以 programmer 的本义近乎“提前写好剧本的人”。

📜 名言 & 谚语

“Talk is cheap. Show me the code.” — Linus Torvalds（Linux 之父，2000年内核邮件列表；空谈无益，代码拿来）

🎵 歌词里的programmer

🎵 David Bowie《Space Oddity》(1969)：Ground Control to Major Tom——地上有人写程序，天上有人在飞行，两头靠信号相连。程序员与宇航员，都是把“不可能”写成日常的人。（主题关联[太空]）

⚡ 冷知识

🔤 世界上第一位程序员是位诗人之女——拜伦的女儿埃达·洛夫莱斯（Ada Lovelace）。1843年，她为巴贝奇的“分析机”写下第一个算法，比第一台电子计算机早了一百多年。程序员的祖师奶奶，既写诗也写代码。
