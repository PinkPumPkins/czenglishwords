1️⃣ 五维拆解法

形·拼写clean up 是“动词+副词”结构：宾语是名词时可以插中间——clean up the room ＝ clean the room up
✏️ 口诀：代词必须中间夹——clean it up ✓，clean up it ✗
音·发音/kliːn ʌp/ clean 长元音 /iː/，up 短促有力
🎧 跟读：clean up · clean it up · clean up the park
意·释义清扫；清理干净——比 clean 更强调“彻底弄干净”，社区大扫除就用它
用·句型① We need to clean up first. ② clean up the community ③ Let's clean it up together.
拓·同族tidy up 收拾整齐 · sweep the floor 扫地 · mop the floor 拖地（同单元家务词）

📋 功能句总结 · Would you like to...? 家务邀请

邀请：Would you like to mop the floor or clean the windows? 回应：I'd like to clean the windows. 指派：Can/Could you please clean up the room? — Sure. / No problem.

👨‍👩‍👧 家长指导卡

家长配合：把周末大扫除变成“家务英语局”——全家抽签决定各自 clean up 的区域，抽完用英语报告（I'll clean up the balcony）；家长带头示范，说错也重来，坚持一个月。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 情景互演：一人扮妈妈发出 Would you like to...? 邀请，另一人用 I'd like to... 接住并指定另一种家务，角色互换；② 改错对决：互出5道“clean it up / clean up it”类判错题，先全对者胜；③ 都完成才一起打卡。

📝 中考考点卡 · clean up

考点1　代词宾语位置：clean it up（代词必须插在中间）
考点2　clean up＋名词＝彻底打扫某处：clean up the classroom
易错　clean up（彻底清扫）≠ tidy up（收拾整齐）——一个去污、一个归位

⚖️ 易混辨析卡 · 别再认错clean up
clean up ↔ clean it up
代词宾语必须放中间——中考单选高频
clean up the room✅ 名词宾语可后置
clean it up✅ 代词必须居中
clean up it❌ 代词后置错误
clean up ↔ tidy up
去污 vs 归位
clean up清扫去污：clean up the kitchen
tidy up收拾整齐：tidy up your desk
🔥 火眼金睛：The room is a mess — let's ______ before guests arrive.
宾语是代词 it 时必须放在动词与副词之间：clean it up。

👪 陪读故事 + 思维导图 + 词源小知识

📖 微型故事《The Sunflower Corner》

小区配电房的墙不知被谁喷了涂鸦，物业的告示贴了一周没人理。周五放学，八(3)班的几个同学蹲在墙根开了个“三分钟会议”：周六上午 clean up，自备涂料。那天来了十一个人，比说好的多了七个——有遛弯的爷爷，也有抱小孩的阿姨。两小时后灰墙变回米白，最会画画的女生在墙角留了一朵小小的向日葵。物业经理拿着登记本跑来问名字，领头的男生只说了一句：“We're from Class 3.”金句：A wall remembers who cleaned it.（墙会记得是谁把它擦干净的。）

🧑‍🏫 自测提问卡：
• 细节题：How many people came on Saturday, and who were the extra ones?
• 推断题：Why do you think the extra neighbours joined without being invited? What does the sunflower at the corner mean?
• 迁移题（开放）：Your class wants to clean up a public place. 用英语写出三步计划（who/where/what to bring）

🗺️ 思维导图

┌── 核心 ── clean up 清扫（动副短语，代词宾语居中） ├── 家务链 ── mop the floor · clean the windows · sweep the floor ├── 社区链 ── clean up the community · clean up the park ├── 语法点 ── clean it up ✓ · clean up it ✗ └── 近义 ── tidy up 收拾 · do some cleaning 打扫

🏛️ 词源故事

clean 的祖先古英语 clǣne，本义“干净的、纯洁的”；up 在这里不是“向上”，而是古英语里表示“彻底、完成”的小副词（eat up 吃光、use up 用完同款）。动副组合 clean up 从16世纪起活跃在英语里，如今连警察治理城市都说 clean up the city——把一个 up 用得这么彻底，只有英语干得出来。

⚡ 冷知识

🔤 中国的“扫尘”习俗定在腊月二十四，寄托“辞旧迎新”；伊朗人在诺鲁孜新年也有 khouneh tekani（掸尘）传统——两大文明隔着几千公里，都相信“把屋子扫干净”是一年中最要紧的仪式之一。
