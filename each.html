1️⃣ 五维拆解法

形·拼写each 4个字母：e-a-c-h；-each 家族成员：teach 教 · reach 到达 · beach 海滩 · peach 桃
✏️ 首字母变，家族不变
音·发音/iːtʃ/ 长元音 /iː/ 拉满，ch 读 /tʃ/
🎧 跟读：each · each other · each student
意·释义adj. & pron. 每个；各自——强调一个一个数过去，人人有份
用·句型① Greet each other. ② Each student has a name card. ③ Each of us has a dream.（谓语用单数！）
拓·同族each other 互相 · each time 每次 · every 每一（强调整体）

📋 功能句总结 · each 的两种姿势：形容词与代词

each + 单数名词：Each student has a card. each of + 复数名词 + 单数动词：Each of us has a card. each other 互相（固定短语，不能拆） 对比 every：every 只能作形容词（every student），each 还能单独当主语。

👨‍👩‍👧 家长指导卡

家长配合：晚饭时玩"一个一个数"游戏——家长报中文（每个/互相），孩子用 each 或 each other 造一句家里的事（Each of us has a cup. We thank each other.）；一周五天，打卡表贴冰箱上，全对周末加一个菜。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 谓语对决：各出3道 Each of... 单选互测，错一题背一遍"each of 谓语单数"口诀；② -each 家族抢答：轮流报 teach/reach/beach/peach 的中文，3秒答不出者出局；③ 全部通过后互相打卡，赢的下次先选游戏关。

📝 中考考点卡 · each

考点1　each of + 复数名词 + 单数动词：Each of us has a card.
考点2　each other 固定短语，中间不加冠词：say hi to each other
易错　each 强调个体（逐个），every 强调整体（全都）；each 可作代词单独作主语，every 不行。听力尾音：each /iːtʃ/ ≠ eat /iːt/

⚖️ 易混辨析卡 · 别再认错each
each ↔ every
近义不同焦：each 逐个看个体，every 全体打包看
each个体视角，可作代词：Each student has a card. / Each of us has...
every整体视角，只作形容词：Every student has a card. ✗ Every of us has...
each /iːtʃ/ ↔ teach /tiːtʃ/ ↔ reach /riːtʃ/
-each 家族：首辅音变、尾音不变——拼写连带记
teachv. 教：Teachers teach us English.
reachv. 到达；伸手够到：Reach for your dream.
each每个：each other 互相
🔥 火眼金睛：选对：Each of the students ______ a name card.
each of... 作主语，谓语用单数 has。each 强调"逐个"，语法上按单数处理。

🟡 中阶 · 家长/自学加油站
👪 陪读故事 + 思维导图 + 词源小知识

📖 微型故事《One Word Each》

单词接龙赛的规则很硬：每人只发一张词卡，each 小组要用卡上的词编一个完整故事。李文抽到 each，王朗抽到 spell，俩人对着空气卡了一分钟。最后李文急中生智，把故事编成一场新生见面会："How do you spell your name?"——"E-A-C-H!"——"Great, now we greet each other!" 评委给了全场最高分。领奖时王朗说：A story is like a class: each of us holds one word, but together we make sentences. 每人一个词，凑在一起才是句子。

🧑‍🏫 自测提问卡：
• 细节题：What two words did Li Wen and Wang Lang get on their cards?
• 推断题：Why do you think the judges gave their story the highest score?
• 迁移题（开放）：你和同桌各有一件"独家本领"，用英语写两句话描述你们怎样互相教（each other）

🗺️ 思维导图

┌── 核心 ── each adj. & pron. 每个；各自 ├── 语法链 ── each + 单数名词 · each of... + 单数动词 · each other 互相 ├── 短语链 ── each time 每次 · each day 每天 · each other 互相 ├── -each 家族 ── teach 教 · reach 到达 · beach 海滩 · peach 桃 └── 辨析 ── each 逐个（个体）≠ every 全体（整体）

🏛️ 词源故事

each 来自古英语 ǣlc，由 ā（永远）+ gelīc（相像）拼成，字面是"永远相像"——每个个体都值得同样的对待。词根 gelīc 正是 like（像）和 -ly 后缀的老祖先，德语 je（各）也是它表亲。所以 each 天生带着"一视同仁"的基因：先承认彼此相像，再一个一个数过去。

🎵 歌词里的each

🎵 Adele《Hello》(2015)："Hello from the other side"——每一通电话都是两个人决定 greet each other 的瞬间。（主题关联：问候·互相）

⚡ 冷知识

🔤 合同和保险条款里有个法律味十足的强调短语：each and every one（每一个人都算）——律师们生怕漏掉任何一个 each，宁可啰嗦也要写全。英语的严谨，就藏在这种"重复"里。
