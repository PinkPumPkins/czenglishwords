1️⃣ 五维拆解法

形·拼写state 5个字母，动词‘陈述’与名词‘状态’同形
✏️ 口诀：站得直（st-）才有状态，说得清才叫陈述
音·发音/steɪt/ 长双元音 /eɪ/ 拉满，对比 skate /skeɪt/
🎧 跟读：in a bad state · the librarian stated · a good state
意·释义n. 状态；国家；州 / v. 陈述；说明——一词四义，语境定夺
用·句型① much of it is in a bad state ② the librarian stated that... ③ the United States 美国
拓·同族statement n. 陈述 · statesman 政治家 · in a good state 状态良好

📝 中考考点卡 · state

考点1　动词用法：state that + 从句（陈述说……）；state one’s reasons
考点2　名词短语：in a bad/good state 状态糟糕/良好；一词多义按语境判断
易错　state /steɪt/ ≠ skate /skeɪt/（滑冰）；‘美国’说 the United States（states 复数）

⚖️ 易混辨析卡 · 别再认错state
state ↔ country ↔ nation
‘国家’三兄弟：state 重政治实体与政权，country 重国土，nation 重民族与国民
statea member state 欧盟成员国（政治实体）
countryChina is a big country. 中国是个大国（国土）
nationthe Chinese nation 中华民族（民族）
state /steɪt/ ↔ skate /skeɪt/
形近音近：开头辅音丛 /st/ 与 /sk/ 之差
staten./v. 状态；陈述：in a good state
skatev./n. 滑冰：go skating 去滑冰
🔥 火眼金睛：判断词性与词义：the librarian stated that...
stated that 后接从句，是动词‘陈述’的过去式；名词 state（州）不能直接接 that 从句。

📖 微型故事《Forty-two Facts》

竞选学习委员，你的对手是连任两届的老班长。轮到你上台，你脱稿只讲了一件事：全班四十二个人，每个人都找你借过笔记——你数过。我不许诺，你说，我只陈述事实，然后改变它。台下静了两秒，掌声才响起来。宣布结果前，班主任在黑板写下一个词：STATE。她说，它既是‘陈述’，也是‘状态’：把事实讲清楚的人，自己先站得住。State your facts, then live up to them. 先陈述事实，再活成它的样子。

🧑‍🏫 自测提问卡：
• 细节题：What fact did the writer state during the speech?
• 推断题：Why do you think stating facts instead of making promises won people over?
• 迁移题（开放）：用英语陈述一条关于你们班的事实（State one fact about your class.）

🗺️ 思维导图

┌── 核心 ── state n. 状态；国家；州 / v. 陈述 ├── 状态链 ── in a bad state · in a good state · state of mind ├── 国与州 ── a member state · the United States · the State of Texas ├── 动词链 ── state that... · state one’s reasons · statement n. └── 词根 ── 拉丁 stare 站 → status / statue / station 同根

🏛️ 词源故事

state 出自拉丁语 status——‘站立的状态’，动词 stare（站）是它的根。同一个 st- 词根撑起了英语一大片：statue（雕像，立着的）、station（车站，驻扎地）、stay（停留）。state 从‘站立的样子’出发，先指‘状态’，再指‘国家体制’（国家‘站’立的形态），又落到美国的‘州’。一个词，站出了三个身份。

📜 名言 & 谚语

“A house divided against itself cannot stand.” — Abraham Lincoln（1858演说，语出《圣经·马可福音》）（分裂之家无所立足——国家（state）与团队同此理）

🎵 歌词里的state

⚡ 冷知识

🔤 美国的每个州都有自己的州歌、州花和州鸟——得克萨斯州的州歌就叫《Texas, Our Texas》（1929年定为州歌）。‘州’在美国不是一个行政区划那么简单：州旗可以和星条旗并排挂，州歌在正式场合要演唱。state 在英语里，从来不只是一个单词。
