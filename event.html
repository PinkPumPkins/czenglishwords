1️⃣ 五维拆解法

形·拼写event 只有5个字母 e-v-e-n-t，头尾都是 e
✏️ 易错：别与 ever / even 混——event 多了 nt，“事”就来了
音·发音/ɪˈvent/ 重音在第二音节，首音节 /ɪ/ 轻读
🎧 跟读：event · events · a big event
意·释义n. 公开活动；重要事情 —— 运动会、义卖、开幕式都是 event
用·句型① The sports meeting is a big event. ② events of the year 年度大事 ③ in the event of fire 万一失火（正式告示）
拓·同族accident 事故（意外）· incident 事件（尤指不愉快的）· eventful 多事的

📢 课本跟读表（含拓展句 · 拓展句已标注）

出处句子

搭配（拓展）sports events 体育赛事 — There are ten sports events this term.（拓展）
拓展（拓展）The opening ceremony was the biggest event of the year.（拓展）
拓展（拓展）In the event of fire, keep calm. 万一失火，保持冷静。（拓展）
📋 功能句总结 · 说“活动”的三个量级

班级活动：Our class will hold a book-crossing event. 班级将办图书漂流活动。 大型活动：The Olympics is a world event. 奥运是世界级盛事。 正式告示：In the event of fire, use the stairs. 万一失火，请走楼梯。

👨‍👩‍👧 家长指导卡

家长配合：家庭日历上标出本月的“三件 event”——学校的、家庭的、社区的，饭桌上各用一句英语播报（The ... is a big event for me because ...）；家长报家庭大事时也用上 event，让孩子体会：活动有大小，大事更值得记录。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 三词判案：互相出5个场景（义卖/骨折/口角/开幕式/演唱会），对方判 event / accident / incident，全对过关；② 播报互测：各自用英语播报一件“本月大事”，对方追问 one of the biggest events 的单复数；③ 一起打卡前互相抽背 event 的三个搭配。

📝 中考考点卡 · event

考点1　one of the biggest events（one of + 最高级 + 复数）
考点2　in the event of + 名词（万一）：In the event of fire...（正式告示）
易错　event（公开活动）与 accident（事故）、incident（不愉快的小事件）混用是完形高频陷阱

⚖️ 易混辨析卡 · 别再认错event
event ↔ accident ↔ incident
中考完形三大“事”：活动、事故、冲突
event公开活动；大事：a big school event
accident意外事故：a traffic accident
incident（不愉快的）小事件；冲突：a border incident
event ↔ ever ↔ even
形近三连：多了 nt 才有“事”
eventn. 活动：a sports event
everadv. 曾经：Have you ever...?
evenadv. 甚至；更：even better
🔥 火眼金睛：The sports meeting is the biggest ______ in our school this term.
运动会是学校组织的公开活动，用 event；accident 是事故，incident 指不愉快的小事件。

🟡 中阶 · 家长/自学加油站
👪 陪读故事 + 思维导图 + 词源小知识

📖 微型故事《Twenty Small Jobs》

班会课上宣布：校艺术节最大的 event——露天义卖，由你们班承办。有人欢呼，有人打退堂鼓。班长把大事拆成二十件小事：海报、定价、找零、卫生，一一认领，只留下一句动员：“A big event is just many small jobs done well.” 义卖当天，你们的摊位排起长队；收摊数钱时，纸箱里的零钱比想象中沉。原来大事不是奇迹，是一群人把小事一件件做完。金句：Big events are built from small jobs. 大事，是小事垒起来的。

🧑‍🏫 自测提问卡：
• 细节题：How did the monitor make the big event manageable?
• 推断题：Why do you think some students wanted to give up at first?
• 迁移题（开放）：What event would you like your class to hold? 用英语列出三个需要完成的“small jobs”

🏛️ 词源故事

event 来自拉丁语 evenire（发生）＝ e-（出来）+ venire（来），名词 eventus 本义是“结果、结局”——在罗马人眼里，一件大事就是“走出来结果”的东西。同一个 venire 还生出了 venue（场地：人们“来”的地方）。event 的祖先关心的不是热闹，而是“最终来了什么结果”。
