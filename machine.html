1️⃣ 五维拆解法

形·拼写machine 7字母，词尾 -ine 读 /iːn/
✏️ 重点：ch 在这里读 /ʃ/，不是 China 里的 /tʃ/
音·发音/məˈʃiːn/ 重音第二音节，ch 发 /ʃ/
🎧 跟读：a machine · machines /məˈʃiːnz/ · a washing machine
意·释义机器（可数名词）——能代替或帮助人工作的装置
用·句型① Machines remove germs from the water. ② Machines inside the plant clean the water. ③ a washing machine
拓·同族machinery 机器总称（不可数，拓展）· mechanic 修理工 · robot 机器人（义近）

👨‍👩‍👧 家长指导卡

家长配合：家里每台电器都是 machine 教具——周末让孩子选三台家电，用英语各写一句 It can...（功能），贴在机身旁；坏掉的小家电拆一颗螺丝看看“机器肚子里有什么”，家长只管安全围栏。孩子说过“这台机器能做什么”，比背十遍名词有感觉。

📝 中考考点卡 · machine

考点1　machine 可数：two machines；machines 作复数主语，动词用原形
考点2　ch 发 /ʃ/：machine /məˈʃiːn/（与 China /tʃ/ 不同）
易错　washing machine 洗衣机（不是 wash machine）；与 robot 辨析：robot 强调自动，machine 泛指装置

⚖️ 易混辨析卡 · 别再认错machine
machine ↔ robot
machine 泛指一切机器，robot 是能自主行动的特殊机器
machine机器（总称个体）：a washing machine
robot机器人：Robots can talk.
machine ↔ march
同字母不同音：machine 的 ch 读 /ʃ/，march 的 ch 读 /tʃ/
machine/məˈʃiːn/ 机器
march/mɑːtʃ/ 行军；March 三月
🔥 火眼金睛：发音判断：machine 中的 ch 读什么音？
machine /məˈʃiːn/ 的 ch 读 /ʃ/（如 shine），与 China /ˈtʃaɪnə/ 的 /tʃ/ 不同，这是高频考点。

📖 微型故事《The Third Button》

班里的旧饮水机坏了，只剩第三个按钮能用——按下去永远出水，不冷不热。总务处说换新要等两周。于是那两周，全班给它起了名字：The Machine。课间排队喝水成了固定节目，有人还给它贴了张纸条：This machine removes our thirst, not our patience. 两周后新机器来了，旧的那台被推走时，居然有同学回头挥了挥手。一台坏了按钮的机器，最后留在了班级日志里——它教会大家：工具不完美时，人的耐心刚好可以补上。

🏛️ 词源故事

machine 的源头是希腊语 mēkhanē（机械、装置）——古希腊戏剧里，“神”常被吊车从天而降解决剧情，人称 deus ex machina（机械降神），这个词今天还在用来讽刺“突然空降的救兵”。经由拉丁语 machina 和法语，machine 在工业时代成了主角。同一词根给了英语 mechanical（机械的）和 mechanic（修理工）——从吊神的绳子，到修车的师傅，两千年是一条线。

🎵 歌词里的machine

🎵 Gladys Knight & the Pips《Midnight Train to Georgia》(1973)：火车是工业时代最早的超级机器，也是这首灵魂乐冠军单曲的“主角座驾”——machine 载着人回家，声音却完全是人味的。（主题关联[旅行交通]）

⚡ 冷知识

🖥️ 1946年2月，美国宾夕法尼亚大学公开 ENIAC——公认的第一台通用电子计算机。它重约27吨，占地约170平方米，每秒能做约5000次加法。今天你手机里那颗芯片每秒的运算量是它的几十亿倍——machine 的进化史，比任何科幻都猛。
