1️⃣ 五维拆解法

形·拼写pass 5字母，双写 s 结尾；过去式 passed；别与 past（过去）混淆
✏️ 一词多义王：及格、通过、传递、流逝
音·发音/pɑːs/ 长元音 /ɑː/；passed 与 past 同音 /pɑːst/——语境定词
🎧 跟读：pass the exam · pass the salt · pass by
意·释义v. 及格；通过；传递；（时间）流逝 n. 及格；通行证
用·句型① I’m sure you’ll pass it. ② Pass me the salt. ③ pass by 路过 ④ Time passes quickly.
拓·同族passage 段落 · passenger 乘客 · passport 护照（通过口岸的凭证）· past 过去（形近）

📋 功能句总结 · pass the exam / pass sth to sb

考试：I’m sure you’ll pass it. — It won’t be easy, but... 传递：Pass the ball to me! = Pass me the ball! 流逝：Two years passed before we met again.

👨‍👩‍👧 家长指导卡

家长配合：饭桌上玩“传菜英语”——Pass me the..., please. 是本周家庭口令，谁说中文谁洗一个碗；孩子月底考试前，家长只说一句 You’ll pass it. 把 pass 的“及格”和“传递”两个意思，都在生活里各跑一遍。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 同音辨义：一人读含 passed/past 的句子，另一人判“通过”还是“过去”，5局3胜；② 多义互测：各用 pass 的三个意思造句，交换判断用义对不对；③ 全对一起打卡，输的一方下节课负责 Pass the... 教具。

📝 中考考点卡 · pass

考点1　pass the exam 通过考试（will pass 表将来）
考点2　pass sb sth = pass sth to sb 传递
易错　passed 与 past 同音 /pɑːst/：动词过去式 vs 名词/介词（in the past）；pass by 路过

⚖️ 易混辨析卡 · 别再认错pass
pass ↔ past
经典陷阱：pass 动词（通过/传递/及格），past 名词/介词/形容词（过去）；passed 与 past 同音
passv. 通过：You’ll pass the exam.
pastn./prep. 过去：in the past / walk past the shop
pass 的多义网：及格 / 传递 / 路过 / 流逝
一词四义，靠搭配锁定：the exam / the salt / by / time
pass the exam及格：I’m sure you’ll pass it.
pass the salt传递：Pass me the salt, please.
pass by路过：The bus passed by.
time passes流逝：Time passes quickly.
🔥 火眼金睛：Could you ______ the salt to me?
Could you 后接动词原形 pass（递给）；past 是名词/介词“过去”，passed 是过去式，均不合句法。

👪 陪读故事 + 思维导图 + 词源小知识

📖 微型故事《The Last Hundred Metres》

体育大考长跑，主角练了一个月才摸到及格线边缘。最后一百米，前面的同学脚下一滑摔在跑道边。他犹豫了半秒，伸手把人拉了起来，两人一起压线——成绩刚刚及格，老师给了两个 pass。有人嘀咕“这样也行？”，老师答：考核通过的是双腿，我看重的还有这双手。金句：通过考试的方式有很多种，最好的那种叫并肩。There are many ways to pass a test; the best one is called side by side.

🧑‍🏫 自测提问卡：
• 细节题：What happened in the last hundred metres, and what was the final result?
• 推断题：Why do you think the teacher gave both of them a “pass”?
• 迁移题（开放）：If helping a classmate might slow you down in a test or race, would you stop? 用英语说理由

┌── 核心 ── pass v. 及格；通过；传递 n. 通行证 ├── 多义链 ── pass the exam · pass the salt · pass by · time passes ├── 同音 ── passed /pɑːst/ = past（语境定词） ├── 词族 ── passage · passenger · passport └── 语境 ── I’m sure you’ll pass it.

🏛️ 词源故事

pass 走的是“脚步”这条路：拉丁语 passus（一步）→ 通俗拉丁语 passare（迈步走过）→ 古法语 passer → 英语 pass。同根的 pace（步速）还保留着“一步”的原义；passport（护照）字面是“通过口岸的凭证”。从迈一步到通过考试，pass 量的一直是你走过的距离。

⚡ 冷知识

🛂 passport（护照）的字面意思是“通过口岸的凭证”（法语 passe-port）——人类最早的“通行证”，管的就是能不能 pass 过一座城门或港口。你书包里那张学生证，也是这个家族的小兄弟。
