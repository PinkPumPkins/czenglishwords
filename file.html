1️⃣ 五维拆解法

形·拼写file 四个字母，i 发双元音 /aɪ/——和 fill（装满）只差长短
✏️ 音辨：file /faɪl/ 双音 ↔ fill /fɪl/ 短音
音·发音/faɪl/ /aɪ/ 滑动到位再收 /l/
🎧 跟读：save a file · a big file · file name
意·释义n. 文件；文件夹——电脑里的“一份完整资料”；也可指纸质的案卷（a file of documents）
用·句型① I saved the file in a new folder. ② Send me the file, please. ③ The file is too big to send.
拓·同族folder n. 文件夹 · document n. 文档 · save v. 保存 · delete v. 删除

file ↔ folder

filen. 文件：a video file 视频文件
foldern. 文件夹：create a new folder 新建文件夹

📖 微型故事《File Zero 零号文件》

班级公用电脑的桌面乱得像操场：三十个“新建文档”挤在一屏。信息课代表阿犁建了一个文件夹，命名为 File Zero——班史。第一条是开学合影，第二条是运动会成绩单。他立了规矩：谁能进文件，全班表决。学期末，File Zero 里有了四十一份文件、两次争吵的和解记录和一张天台合影。有人说这是最无聊的作业，阿犁说：A good file name is a promise to future you. 好的文件名，是写给未来的你的一句承诺。

🗺️ 思维导图

┌── 核心 ── file n. 文件；文件夹（/faɪl/） ├── 操作链 ── save 保存 · open 打开 · delete 删除 · send 发送 ├── 结构链 ── file 文件 → folder 文件夹 → file name 文件名 ├── 辨析链 ── file /aɪ/ 文件 ↔ fill /ɪ/ 装满 └── 词源链 ── 拉丁语 filum 线——文件曾穿在绳上

🏛️ 词源故事

file 走了一条“从线到文件”的路：拉丁语 filum 意为“线”，经古法语 fil 进入英语，先指“穿文件的绳”——过去文书用线穿成一串保存，一串就是一 file。后来绳换成档案柜，档案柜换成硬盘，但名字没换：文件，依然是“穿在一根线上的一串纸”。profile（轮廓）也来自这根线——画在边界线里的像。

🎵 歌词里的file

🎵 Paperback Writer — The Beatles (1966)：披头士替一位“写书的人”喊话——从纸质书稿到电子文件，“把东西写成 file”这件事，六十年一直没停。（补配 · 主题关联：文书写作）

⚡ 冷知识

🔤 电脑里的 file 借用了办公室的说法：1898年美国人西贝尔斯（Edwin Seibels）推广立式档案柜，把文件按字母立着插进抽屉——“file”从此成为办公热词，几十年后才被计算机界借走。先有文件夹，后有电脑，这笔“词汇债”还没还。
