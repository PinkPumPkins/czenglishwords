1️⃣ 五维拆解法

形·拼写main 只有4个字母：m-a-i-n——最短的“高频形容词”之一
✏️ 副词 mainly（主要地）别漏 y；名词 mainland（大陆）是复合词
音·发音/meɪn/ 单音节，/eɪ/ 双元音读满
🎧 跟读：main · mainly · main idea · main text
意·释义adj. 主要的——main idea 主旨 · main text 正文 · main road 干道；没有比较级（本义“最大的”）
用·句型① A topic sentence gives the main idea of a paragraph. ② main text 邮件正文（课本 p59 结构项）③ the main reason 主要原因
拓·同族mainly adv. 主要地 · mainland n. 大陆 · major adj. 主要的（义近）

📋 功能句总结 · main idea 阅读主句型

主旨：A topic sentence gives the main idea of a paragraph. 定位：It usually appears at the start of a paragraph, but it can also appear later on. 正文：main text（邮件六要素之一） 搭配：the main reason/road/street/idea

📝 中考考点卡 · main

考点1　main idea 主旨题（阅读高频）：A topic sentence gives the main idea of a paragraph.
考点2　词性：形容词 main 修饰名词，副词 mainly 修饰动词/句子
易错　main 一般不用比较级（❌ mainner）；main 与 mine /meɪn/ 与 /maɪn/ 听辨；别漏写 mainly 的 y

⚖️ 易混辨析卡 · 别再认错main
main /meɪn/ ↔ mine /maɪn/
音近双料：双元音 /eɪ/ 与 /aɪ/ 一字之差，听力高频陷阱
mainadj. 主要的：the main idea
minepron. 我的：That book is mine.
main ↔ major
义近辨析：main 最常用，major 带出“级别高”的意味
main主要的：the main reason
major主要的；重大的：a major problem
🔥 火眼金睛：选词填空：A topic sentence gives the ______ idea of a paragraph.
修饰名词 idea 要用形容词 main（课本 p56 原句）；mainly 是副词，用来修饰动词或全句。

📖 微型故事《Find the King》

月考阅读题发下来，全班哀嚎一片——文章又长又绕，页码还多。同桌却十分钟做完，还剩时间检查。你问他秘诀，他把笔往卷子上一放，只说：“Find the main idea—擒贼先擒王。” 你试了一遍：每段先找中心句，再回头做细节题，正确率肉眼可见地涨了。两周后的错题本上你写：Reading is not about understanding every word, but about catching the main idea. 阅读不是读懂每个词，而是抓住最有力气的那一句。

🗺️ 思维导图

┌── 核心 ── main adj. 主要的（mainly adv. 主要地） ├── 搭配链 ── main idea 主旨 · main text 正文 · main road 干道 · the main reason ├── 策略链 ── topic sentence 中心句 → main idea 主旨 → detail questions 细节题 ├── 同族 ── mainland 大陆 · major 主要的（义近） └── 词源 ── 古英语 mægen“力量”→ might and main 全力以赴

🏛️ 词源故事

main 来自古英语 mægen（力量），和 might（力量；情态动词 may 的过去式）是同源兄弟——英语成语 with might and main（全力以赴）里，两个“力”字并肩站了几百年。main 的本义是“大的、有力的”，后来才收窄成“主要的”。main idea 主旨，就是一段话里“力气最大”的那一句。

📜 名言 & 谚语

“射人先射马，擒贼先擒王。” — 杜甫《前出塞九首》（抓主要目标——读文章也一样：先抓 main idea）

🎵 歌词里的main

🎵 Bob Seger《Mainstreet》(1976，专辑《Night Moves》)：一条小城主街的夜色回忆，歌名就是 main street——美国的镇上几乎都有一条“主要的街”。（歌名含词）·（补配）

⚡ 冷知识

🔤 美国人口普查局统计街道名，最常见的不是 Main Street，而是 Second Street——数字路名几乎每个镇都有一条，Main 反而排不到第一。“第二”比“主要”更常见，统计偶尔很幽默。
