1️⃣ 五维拆解法

形·拼写run low (on sth)：run（变得）+ low（低）——不是“跑得低”，是“降到低位”
✏️ run 在此是系动词用法，后接形容词
音·发音/rʌn ləʊ/ 动词原形；进行时 be running low 最常用
🎧 跟读：running low · run low on fuel · run low on patience
意·释义即将用尽；快用完（短语动词）——库存、电量、燃料、耐心都能 run low
用·句型① when you’re running low（课本句）② My phone is running low on power. ③ We are running low on time.
拓·同族run out (of) 用完（强调耗尽）· run low on sth 接具体对象 · supplies n. 物资

📢 课本跟读表（含拓展句 · 拓展句已标注）

出处句子
拓展（拓展）We are running low on milk. 我们的牛奶快没了。
拓展（拓展）My phone battery is running low. 我的手机电量快耗尽了。
拓展（拓展）Petrol is running low—find a station! 油快没了，快找加油站！

📋 功能句总结 · be running low (on sth) 告急句

句型：Sth is running low. / Sb is running low on sth. 同义：We are running out of milk. = Milk is running low. 对象：power 电量 · fuel 燃料 · time 时间 · patience 耐心

👨‍👩‍👧 家长指导卡

家长配合：让孩子当一周“家庭物资官”——每晚用英语播报存货：We are running low on eggs/milk/rice. 家长负责次日按“播报”补货；孩子播报得越勤，run low 的用法越熟。家里的冰箱，就是最日常的听写本。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 听辨对决：一人读 run low / run slow，另一人判断开头，5局3胜；② 句式互换：轮流把 running low on 句和 running out of 句互译，全对才算赢；③ 各自录一条15秒“家庭物资播报”（We are running low on ...）发对方验收，通过后一起打卡。

📝 中考考点卡 · run low (on sth)

考点1　常用进行时：be running low (on sth) 正在告急
考点2　两种句式转换：sth is running low = sb is running out of sth
易错　run low 是“快用完”（还有余量），run out of 是“用完了”（没了）——程度不同；❌ run lowly → ✅ run low（此处 low 是形容词）

⚖️ 易混辨析卡 · 别再认错run low (on sth)
run low (on) ↔ run out (of)
程度之差：run low 快用完（还剩一点），run out of 用完了（没有了）
run low on快用完：We are running low on milk.
run out of用完：We ran out of milk yesterday.
run low ↔ run slow
音近辨析：run low 快用完，run slow 慢慢跑
run low快用完：My battery is running low.
run slow跑得慢：The old engine runs slow.
🔥 火眼金睛：选出正确的一项：
表示“某物快用完”要加介词 on：be running low on sth；on time（按时）是另一义，此处 on time 表对象。

📖 微型故事《One Night Before the Fair》

义卖节前夜，社团的彩纸 run low 了，预算也见了底。有人提议放弃，组长却说：We are low on money, not on ideas. 全队把旧挂历翻面做海报纸，瓶盖串成风铃，旧CD挂在窗前当阳光板。第二天，他们的摊位卖爆全场，收入超出目标一倍。总结会上组长写下一句话：资源见底的时刻，恰是创意开工的时刻。When supplies run low, ideas run high. 物资见底时，创意满格。

🧑‍🏫 自测提问卡：
• 细节题：What materials did the team run low on, and what did they use instead?
• 推断题：Why do you think their stall sold twice as well as expected?
• 迁移题（开放）：What would you make if your supplies ran low before a school fair? 用英语说出你的替代方案

🏛️ 词源故事

run 是英语最古老的动词之一，本义“流淌、延伸”——河流 run，时间 run，机器 run。run low 保留的是“液面降到低位”的画面： tank run low（油箱见底）、patience run low（耐心见底）。英语里 run 管液体是千年老用法（running water 流水），所以“快用完”用的不是 finish，而是 run——像水一样降下去。

🎵 歌词里的sth)

🎵（补配）Jackson Browne《Running on Empty》(1977)：公路经典——“Running into the sun, but I’m running behind”唱尽了油量告急、精力告急的人生旅途。（主题关联：耗尽/告急）

⚡ 冷知识

🔤 地球的水97%是海水，淡水不到3%，而其中大部分冻结在冰川和两极——人类真正方便取用的地表淡水只占极小比例。所以“水资源 run low”不是修辞，而是许多城市每天都在面对的清单：这大概是课本这句话最该被记住的现实版本。
