1️⃣ 五维拆解法

形·拼写pull together 三个词都能独立，together 里藏着 gather（聚拢）
✏️ 口诀：绳子往一处拉，人心往一处聚
音·发音/pʊl təˈɡeðə/ together 重音在 -ge-；连读 pull-to-ge-ther
🎧 跟读：pull together · work together · get together
意·释义齐心协力；通力合作——把力气往同一个方向拉（动词短语）
用·句型① If we pull together, we should win next time.（课本原句）② Pull together, class! ③ We pulled together to finish the project.
拓·同族work together 合作 · get together 聚会 · together adv. 一起

👨‍👩‍👧 家长指导卡

家长配合：家里练 pull together 最自然的地方是家务——大扫除时全家分工，家长只喊英语口号 One for all!，孩子接 all for one!；月末一起复盘哪次配合最顺、哪次各干各的。合作的语感是在一起干活时长出来的，不是背单词背出来的。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 口号互喊：一人喊 One for all!，另一人必须 1 秒内接 all for one!，接慢或接错做5个深蹲；② 互译互批：各自把课本句 If we pull together, we should win next time. 换场景改写（家务/值日/合唱），交换批改主谓一致；③ 都完成后互相打卡，输的一方下次拔河当“喊口号的”。

📝 中考考点卡 · pull together

考点1　主语 we/they 时 pull 用原形：If we pull together...
考点2　口号 One for all, and all for one.（写作引用加分）
易错　❌ pull our together → ✅ pull together（固定短语，中间不加代词）；过去式 pulled together

⚖️ 易混辨析卡 · 别再认错pull together
pull together ↔ get together
pull together 为共同目标协力；get together 只表“聚会、集合”——有没有“劲往一处使”是分界
pull together to win齐心协力去赢
get together for dinner聚个餐
pull ↔ push
反义方向组：pull 拉 / push 推——门上的 Pull 是“拉”不是“推”
pull the rope拉绳子
push the door推门
🔥 火眼金睛：选词填空：If we ______, we can finish the poster before lunch.
get together 表“聚会集合”，不强调协力完成任务；为共同目标出力用 pull together.

📣 关卡1 · 听辨关 · 短语识别
同桌交替读 pull together / get together，你判断哪个是“齐心协力”、哪个是“聚会集合”——听 to 前的动词就能分清
✏️ 关卡2 · 语法关 · 中考单选
If we ______ together, we can win next time.
A. pull　B. pulls　C. pulled → A（主语 we 用动词原形）
✅ 关卡3 · 语境关 · 排序组句
打乱的课本句还原：win / we / together / if / pull / should / we → If we pull together, we should win.

📖 微型故事《One Rope, Twelve Hands》

校运会拔河决赛，秦朗所在的二班第一局就输了，绳子一松，人心也跟着散。他站到队首喊：Pull together! 一——二——拉！第二局，十二双手同时发力，红布条一点点挪回中线。决胜局，口号声盖过整个操场，二班赢了。喊哑了嗓子的秦朗被同学们抛到空中。他在周记里写：一根绳上的人，心也在同一根绳上。All for one, and one for all. 齐心的时候，绳子不重，风也是顺风。

🏛️ 词源故事

pull 来自古英语 pullian（拔、扯），本义就是手上那一下“拽”；together 是 to + gather（聚拢）的古老合体，德语表“一起”的 zusammen 也是“聚到一处”的意思。pull together 字面就是“往一处拉”——这个短语用了几个世纪，画面感从未变过。合作这个词，英语从一开始就把它画成了一个动作。

⚡ 冷知识

🔤 拔河（tug of war）曾是正式奥运项目——1900年到1920年连续出现在五届奥运会上，1920年安特卫普奥运会后才退出；奖牌榜上英国队排在前列。Pull together 这件事，人类真的为之发过奥运金牌。
