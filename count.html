1️⃣ 五维拆解法

形·拼写count 五个字母，ou 组合发 /aʊ/
✏️ 形近警报：mount（山，现代英语仅用于山名）；发音别与 can’t /kɑːnt/ 混
音·发音/kaʊnt/ 双元音 /aʊ/ 要滑动到位，词尾 /t/ 清晰
🎧 跟读：Let me count. · count from 1 to 100 · count on sb
意·释义v. 数数；计算——本义是"一个一个地点"，延伸为"重要"（Every vote counts.）
用·句型① Let me count. ② Count from one to one hundred. ③ You can count on me.（依靠）
拓·同族count on sb 依靠某人 · countable 可数的 · counter 计数器 · account 账户（同源亲戚）

📋 功能句总结 · Let me count. + How many...?

数数：Let me count. One, two, three... 问：How many cows do you see? 答：I see seven. 进阶：count from A to B 从A数到B · count on sb 依靠某人

👨‍👩‍👧 家长指导卡

家长配合：把数数变成家庭"擦碗券"——晚饭后用英语 count 楼梯台阶、碗筷数量，数错的人多擦一只碗；每月听写盯 count from...to... 和 count on 搭配。数字是孩子最先学会也最容易生锈的英语，一周一次"数数日"就能保住它。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 数字接龙：从1数到30英语接力，逢7和7的倍数拍手并说 seven，数错换人；② 双义对决：一人说 count the books / count on him，另一人3秒内翻译，共8句，对6句过关；③ 两关都完成一起打卡，输的一方下周帮班级钱箱数两次——count twice, trust once.

📝 中考考点卡 · count

考点1　Let sb do：Let me count.（let 后接动词原形）
考点2　count from A to B；count on sb = depend / rely on（依靠）
易错　count /kaʊnt/ ≠ mount /maʊnt/；count（数）与 count（伯爵）同形不同源；fourteen 别写成 fourtien

⚖️ 易混辨析卡 · 别再认错count
count ↔ mount
形近词：只换首辅音，/k/ 数数，/m/ 是山
countv. 数：Let me count.
mountn. 山（现代英语主要用于山名前）：Mount Tai
count（数）↔ count on（依靠）
同词不同义：接不接 on，意思差一层
count数数：Count from one to ten.
count on依靠：You can count on me.
🔥 火眼金睛：单选：I can count ______ one to one hundred.
count from A to B 是固定搭配，"从A数到B"；at 和 of 都不与 count...to... 搭配。

📖 微型故事《The Third Counting》

班级义卖会收摊，钱箱交给"最细心"的何小满。第一遍数：八十六元。第二遍：八十八。第三遍：八十四。她的耳朵红了，围观的同学越聚越多。班长说：分堆数，十元一摞。五分钟后答案出来：八十八元——果然有一张十元，被当成五元数了两次、又漏了一次。何小满在义卖总结里写：Number one rule: count twice, trust once. 数字不信眼泪，只信方法。后来这句成了班里的"财务法"第一条，贴在钱箱上，一直贴到毕业。

🧑‍🏫 自测提问卡：
• 细节题：Why did He Xiaoman get three different numbers?
• 推断题：Why does the writer call it "count twice, trust once"? 这个方法还能用在哪里？
• 迁移题（开放）：用英语数一数你今天的"三样收获"，再用一句 I can count on... 说说你信任谁

🗺️ 思维导图

┌── 核心 ── count v. 数数；计算（Let me count.） ├── 短语链 ── count from A to B · count on sb 依靠 · count down 倒计时 ├── 句型 ── How many...? — I see seven. ├── 易混 ── count ≠ mount（山）；count（数）与 count（伯爵）不同源 └── 文化 ── compute 是它的拉丁亲兄弟 · Count on Me 的承诺

🏛️ 词源故事

count 经古法语 conter 回溯到拉丁语 computare（计算）——com-（一起）+ putare（估算）。它有个坐火箭的兄弟：compute，直接从拉丁语整词借入，后来生出了 computer。所以 count 和 computer 是名副其实的远房表亲：一个用手指，一个用芯片，干的是同一件几千年的老活。更妙的是英语还有另一个 count（伯爵），来自拉丁语 comes（同伴）——两个 count 拼写相同，祖宗不同。

📜 名言 & 谚语

"Not everything that can be counted counts, and not everything that counts can be counted." — William Bruce Cameron（能数出来的未必重要，重要的未必数得出来——此句常被误传为爱因斯坦语）

🎵 歌词里的count

🎵 Bruno Mars《Count on Me》(2011)："You can count on me like one, two, three"——把"依靠"唱成数数节拍，一句副歌就把 count on 装进长期记忆。（歌名含词）

⚡ 冷知识

🔤 count 作动词"数数"来自拉丁语 computare，作名词"伯爵"却来自拉丁语 comes（随从）——两个 count 是拼写相同的陌生人。英语里还有 viscount（子爵）和 viscountess（子爵夫人）。一个管数字，一个管爵位，互不打扰。
