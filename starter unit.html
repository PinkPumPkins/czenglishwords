1️⃣ 五维拆解法

形·拼写start（开始）+ -er（后缀）＝ starter，再牵手 unit（单元）——两个熟词合成一个术语
✏️ 类比记忆：starter unit 就是正式单元前的"热身赛"
音·发音/ˈstɑːtə(r) ˈjuːnɪt/ -er 在英音读 /ə(r)/，美音读 /ɚ/
🎧 跟读：starter unit · Starter Units 1–3
意·释义n. 过渡单元——正式单元前的衔接单元；starter 也指"启动器；开胃菜；（赛跑）发令员"
用·句型① Starter Units help you get ready. ② Finish the starter unit first. ③ For starters, let's greet each other.
拓·同族for starters 首先 · starter motor 启动电机 · 同族：runner 跑者 · singer 歌手（-er 表"…者"）

📝 中考考点卡 · starter unit

考点1　构词 start + -er → starter，同类 runner/singer/driver；陷阱：cooker 是"炊具"不是"厨师"
考点2　For starters, ... 首先（阅读理解常见习语）
易错　star /stɑː(r)/（星星）↔ start /stɑːt/（开始）↔ starter /ˈstɑːtə(r)/——尾音 /t/ 和 /ə(r)/ 决定词义

⚖️ 易混辨析卡 · 别再认错starter unit
star /stɑː(r)/ ↔ start /stɑːt/ ↔ starter /ˈstɑːtə(r)/
三连音近词：差一个尾音，差一个身份
starn. 星星；明星：The stars are bright tonight.
startv. 开始：Let's start now.
startern. 启动者；开胃菜：a salad starter 蔬菜开胃菜
🔥 火眼金睛：英式菜单上的 starter 指什么？
餐厅菜单里 starter = 第一道开胃菜；机器旁的 starter 才是启动器。一词多义靠场景定。

📣 关卡1 · 听辨关 · 尾音陷阱
同桌读词，你判断听到的是 star /stɑː(r)/、start /stɑːt/ 还是 starter /ˈstɑːtə(r)/——一个尾音差一个身份
✏️ 关卡2 · 语法关 · 构词填空
按 -er 规则写名词：run → runner，sing → singer，drive → driver，start → starter；警惕陷阱：cooker 是"炊具"不是"厨师"

📖 微型故事《Three Warm-up Laps》

转学生李想翻开课本直皱眉：三个 starter unit 全是 hello、hi、bag，太简单了，不如直接跳到 Unit 1。第一次随堂测，他在听力里把 spell 听成了 smell，阅读里没认出 tidy，红笔比他的铅笔还多。班主任只说了一句："跳过热身圈的人，正式比赛容易拉伤。"李想回去把三个 starter unit 重学一遍：每个词听五遍，每句抄一遍。月考时，他的红笔第一次帮别人改了错。他在扉页写：Warm-up is not slow — it is smart. 热身不是慢，是聪明。

🏛️ 词源故事

start 来自古英语 styrtan，本义"跃起"——像受惊的马猛地一跳，"开始"这层意思正是从"猛然一动"引申来的。加上 -er 后 starter 一路多职：赛场上是发令员，厨房里是开胃菜（20世纪英式菜单的用法），引擎盖下是启动器。德语 stürzen（俯冲）是它的表亲——一个从马背跳进发动机的词。

🎵 歌词里的unit

🎵 The Beatles《Hey Jude》(1968)：Paul McCartney 为安慰五岁的 Julian 写下的歌——"Take a sad song and make it better"，像拍着新生肩膀的一句问候，正好给热身阶段加油。（主题关联：问候·鼓励）

⚡ 冷知识

🔤 田径场上喊 "On your marks, get set, go!" 的裁判就叫 starter（发令员）。2011年大邱世锦赛百米决赛，博尔特因抢跑（false start）被直接取消资格——全世界最快的人，输给了一个"太想 start"。热身和起跑的纪律，比天赋先说话。
