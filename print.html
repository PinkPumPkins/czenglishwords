1️⃣ 五维拆解法

形·拼写print 5个字母，与 press 同祖（拉丁 premere 压）——压出印，印出书
✏️ 辨析警报：paint 上色/画 ↔ print 印刷/打印——开头一个字母之差
音·发音/prɪnt/ /ɪ/ 短促，/nt/ 收紧
🎧 跟读：print out the paper · in print · a hand print
意·释义n. 印刷品；v. 打印；印刷——从古腾堡的铅字到你家的打印机，动词没换过
用·句型① Please print out the article. ② The book is still in print. ③ print the poster for the show
拓·同族printer n. 打印机 · printout n. 打印件 · press n. 出版社/按压（同源）

📢 课本跟读表（含拓展句 · 拓展句已标注）

出处句子
常用搭配Please print out the article for me. 请帮我把这篇文章打印出来。
常用搭配The old dictionary is out of print now. 那本旧词典现在已绝版。
拓展（拓展）同源链：press 按压 → print 印刷 → printer 打印机 → printing press 印刷机
拓展（拓展）辨析：paint 用颜料涂/画 ↔ print 印刷/打印——Paint is by hand; print is by machine.
📋 功能句总结 · print out + in print / out of print

操作句：Print out the report before class. 课前把报告打印出来。 出版句：His first book went out of print quickly. 他的第一本书很快绝版了。

📝 中考考点卡 · print

考点1　print out 打印出来（out 补完动作）
考点2　in print 已出版 ↔ out of print 绝版
易错　paint（涂/画）≠ print（印/打印）——音近形近，写作高频混用；printer 是机器不是动作

⚖️ 易混辨析卡 · 别再认错print
paint ↔ print
p 开头双雄：paint 用颜料涂/画（手工），print 印刷/打印（机器）——开头一字母之差
paintv. 涂；画：paint the wall / paint a picture
printv. 打印；印刷：print out the photo
print ↔ printer
动词机器分家：print 是动作，printer 是打印机（+er 表器具）
printv. 打印：print the document
printern. 打印机：a new printer

📖 微型故事《黑白版的反击》

班报第三期的印刷机排期撞了车。主编沈度临时决定：先印两百份黑白版应急，彩色版下期补。结果黑白版反而被夸了——标题的粗黑衬线、插图的灰阶层次，全靠两天排版返工。彩色版出来后，他们把两版并排钉在班报栏，配了一行小字：“同一篇文章，两种 print，两种性格。”美术老师在下面批：Content carries a newspaper, but print gives it a face.——内容撑起报纸，印刷给它一张脸。

🏛️ 词源故事

print 与 press 是亲兄弟：拉丁语 premere（压）→ 古法语 preinte（压出的印）→ 英语 print。“压出痕迹”是印刷的全部秘密——铅字压在纸上，手压在印章上，脚印（footprint）压在沙上，指纹（fingerprint）压在指尖，逻辑同一条。press 家族人口兴旺：pressure（压力）、imprint（印记/深刻影响）、impressive（令人印象深刻的——字面“压进心里的”）。印刷术的伟大，本质是“压”的伟大。

⚡ 冷知识

🖨️ 古腾堡《四十二行圣经》约在1455年印成，学界估计印量约180册，存世至今约49册——一册现存书页值一套房。中国宋代毕昇的活字术早它四百年，谷登堡的功劳是把活字、油墨与螺旋压印机拧成了一条“生产线”。print 这个词，站在两个文明的肩膀上。
