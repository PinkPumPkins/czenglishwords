1️⃣ 五维拆解法

形·拼写IT 只有2个字母，但必须都大写——它是缩写，不是普通单词 it
✏️ 全称 information technology，两个词拼出 IT
音·发音/ˌaɪ ˈtiː/ 按字母逐个读“艾-替”，重音在后
🎧 跟读：IT class · an IT lesson · learn about IT
意·释义abbr. 信息技术（= information technology）——电脑、网络、编程的统称，也是一门课
用·句型① I like to learn about IT. ② We have an IT class every week. ③ Peter doesn’t like maths / IT because it’s boring / difficult.
拓·同族technology n. 技术 · tech（口语缩略） · digital 数字的 · computer science 计算机科学

👨‍👩‍👧 家长指导卡

家长配合：请孩子当一次“IT小老师”——用英语向你演示电脑或手机里的一个功能（Type here. Click here.），你负责提两个问题；顺便听写 IT 的全称 information technology，重点盯 technology 的拼写，别写成 tecnology。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 听辨对决：同桌各读三组 it /ɪt/ 与 eat /iːt/，举牌判断，5局3胜；② 缩写互考：轮流说出 IT、TV、CD 的全称或含义，说不出的一方做5个深蹲；③ 各自完成“IT用途三句话”后互批互改，两句都过关才一起打卡。

📝 中考考点卡 · IT

考点1　IT 全称 information technology，两个字母均大写
考点2　句型 like to do sth：I like to learn about IT.
易错　an IT class（/aɪ/ 元音音素开头用 an）；缩写 IT 与代词 it 的身份区分；technology 拼写别丢 ch

⚖️ 易混辨析卡 · 别再认错IT
IT ↔ it
两个字母定身份：大写是学科缩写，小写是代词“它”——考试写错大小写直接扣分
ITabbr. 信息技术：I like to learn about IT.
itpron. 它：It’s exciting!
🔥 火眼金睛：中考单选：We have ______ IT class every Monday.
IT /ˌaɪ ˈtiː/ 以元音音素 /aɪ/ 开头，前面用 an；这不是按字母 I 是否元音字母判断，而是按读音。

📖 微型故事《Two Letters and a Broken Printer》

班里第一次用英语做电子简报，打印机的驱动偏偏在课前十分钟罢工。全班围着它干瞪眼，班长说：找陈一诺。她蹲下来重启、换线、重装，五分钟后纸出来了，还顺手把版式调好。外教竖起大拇指：“Your IT skill is amazing!” 陈一诺耸耸肩：其实我只是爱折腾。当晚她在周记里写下一句话：IT is not magic; it is patience plus curiosity. 信息技术不是魔法，是耐心加上好奇心。

🧑‍🏫 自测提问卡：
• 细节题：What broke down ten minutes before class, and who fixed it?
• 推断题：Why do you think she described herself as “爱折腾” instead of “厉害”?
• 迁移题（开放）：What IT skill do you want to learn this term? 用英语写一句计划

🗺️ 思维导图

┌── 核心 ── IT abbr. 信息技术（= information technology） ├── 全称链 ── information 信息 + technology 技术 = IT ├── 课堂链 ── IT class · learn about IT · an IT lesson ├── 同族 ── technology 技术 · tech · digital 数字的 └── 句型 ── I like to learn about IT. · We have... class

🏛️ 词源故事

information 来自拉丁语 informare（塑造、传达概念——把“形”装进对方心里）；technology 则是希腊语 technē（技艺）与 -logia（学说）的组合。20世纪中叶计算机产业兴起后，information technology 缩写成 IT。有趣的是缩写的命运分岔：小写的 it 只是英语里最短的功能词之一，一旦两个字母都大写，就从“它”升级成了改变世界的技术。

📜 名言 & 谚语

“Any sufficiently advanced technology is indistinguishable from magic.” — Arthur C. Clarke（克拉克第三定律：足够先进的技术与魔法无异）

🎵 歌词里的IT

🎵 Michael Jackson《Beat It》(1983)：“Just beat it”——歌名里正好藏着两个字母 it，大写一下就是 IT。MJ 用最短的词唱出最烈的节奏：简单，从来不等于是没有力量。（歌名含词：it）

⚡ 冷知识

🔤 1946年诞生的第一台通用电子计算机ENIAC重约27吨、占地约170平方米，每秒只能完成5000次加法运算；今天你口袋里的手机每秒能运算数万亿次。IT用不到80年，把一整个机房塞进了口袋。
