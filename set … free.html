1️⃣ 五维拆解法

形·拼写中间是省略号占位——set + 宾语 + free，宾语必须夹在中间
✏️ 口诀：set 夹宾语，free 收尾：set him free ✓，set free him ✗
音·发音/set friː/——free 长元音 /iː/，与 three /θriː/ 只差一个咬舌音
🎧 跟读：set him free · set them free · set the bird free
意·释义释放（使某人/某物获得自由——魔鬼赌了一辈子就等这句：If someone set me free）
用·句型① If someone set me free, I would make them rich. ② set the bird free 放飞小鸟 ③ set ... free = let ... go 同义
拓·同族家族：free adj. 自由的/免费的 · freedom n. 自由 · for free 免费

📋 功能句总结 · set + 宾语 + free：宾语夹中间的使役短语

正确语序：set him free ✓ / set the bird free ✓ 错误语序：✗ set free him（代词宾语必须夹在 set 与 free 之间） 同义替换：set ... free = let ... go（释放） 课本语境：If someone set me free, I would make them rich and powerful.

👨‍👩‍👧 家长指导卡

家长配合：用家里的“放生时刻”练这个短语——阳台放归小鸟、解救卡在栏杆的猫，一句 set it free 说出口就算完成家庭练习；顺便聊一句：魔鬼为什么非要别人 set him free？让孩子用英语答，你只负责追问为什么。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 语序互纠：一人快速念 set free + 代词的句子（含错误版），对方秒判对错，10句记分；② 听辨局：free / three 各读5次，举 A/B 牌，互看口型纠咬舌咬唇；③ 全过后互相在对方页面打卡，输的一方把甘地名言抄进摘抄本。

📝 中考考点卡 · set … free

考点1　语序：set + 宾语 + free（set them free）；宾语是代词时必须夹中间
考点2　同义替换 set ... free = let ... go；want sb to do：want someone to set him free
易错　free 是形容词作宾补，不是副词；❌ set free him（代词宾语）——与 pick it up 同类语序考点

⚖️ 易混辨析卡 · 别再认错set … free
set ... free ↔ let ... go
同为“释放”：set...free 强调结果（自由了），let...go 强调动作（松手）
set ... free结果：The boy set the bird free.
let ... go动作：Let go of my hand! / Let it go.
free ↔ freely
free 形容词作宾补（set them free）；freely 副词修饰动作“自由地”
freeadj. 宾补：set the bird free
freelyadv. 修饰动词：The bird flies freely in the sky.
🔥 火眼金睛：选词填空：The fisherman wanted someone ______ the genie free.
want sb to do sth：want someone to set the genie free；set 本身不带到不定式里。

📖 微型故事《The Open Jar》

生物社团的蝶蛹破茧了。有人提议做成标本，评奖稳拿；社长摇头，把玻璃罐搬到了操场。罐口打开，蝴蝶在边缘停了两秒，忽然振翅冲进阳光里——飞过篮球场，飞过旗杆，直到变成一个白点。社长说：“It's free now.”，声音却有点哑。评比结果出来，社团没拿到奖，却多了一条新社规：任何生物，观察一周后 set free。To love something is to be able to set it free.（爱一样东西，就是敢把它放走。）

🧑‍🏫 自测提问卡：
• 细节题：Where did the club take the jar at last?
• 推断题：Why did the president refuse to make the butterfly a specimen even though it could win a prize?
• 迁移题（开放）：If you love something, should you keep it or set it free? 用英语说两句

🏛️ 词源故事

free 的家谱有点暖：古英语 frēo“自由的”与 friend（朋友）同出原始印欧词根 *priH-（爱）——在古人的世界里，“自由的人”就是“被爱着的人”，朋友则是“你自由选择去爱的人”。与 set（使坐下）拼在一起，set ... free 的字面几乎是一幅画：把“自由”稳稳安放到它该在的位置上。把一样东西还给自由，就是把它还给它所爱的人。

词构成与含义

let ... go同义：放开；放走
freeadj. 自由的；空闲的；免费的
freedomn. 自由（-dom 抽象名词后缀）

📜 名言 & 谚语

“Freedom is not worth having if it does not include the freedom to make mistakes.” — 圣雄甘地《青年印度》(1921)（不包括犯错的自由，就不配叫自由）

🎵 歌词里的free

🎵 Queen《I Want to Break Free》(1984)（补配）：“I want to break free!”——皇后乐队唱出了所有被关在瓶子里的心声。魔鬼赌了一辈子等一句 set me free，歌里只要三秒就唱完——语言比等待痛快。（歌名含词·free）

⚡ 冷知识

🔤 电影《威鲸闯天关》(Free Willy, 1993) 里的虎鲸 Keiko，现实中真的被“释放”了：1998年运回冰岛近海适应野生环境，2002年7月正式放归大海，随后游到挪威近岸，2003年底在挪威去世。这是影史上最著名的一次 set ... free——从剧本照进现实。
