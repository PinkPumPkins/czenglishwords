1️⃣ 五维拆解法

形·拼写动词短语：make + up——可分式短语动词
✏️ 代词必须插中间：make it up ✓ / make up it ✗
音·发音/ˌmeɪk ˈʌp/ make 和 up 连读，up 重读
🎧 跟读：make up (with sb) · make up after a quarrel · make up for it
意·释义与……言归于好（本单元义）；引申义还有编造、组成、化妆等
用·句型① argue but don’t know how to make up ② They made up with each other. ③ I’m sorry — let’s make up.
拓·同族make up for 弥补 · makeup n. 化妆品 · make friends with 交朋友

劝和：Why don’t you make up with him? 你为什么不跟他和好？ 主动：I’m sorry. Let’s make up. 对不起，我们和好吧 补救：I’ll make it up to you. 我会补偿你的

👨‍👩‍👧 家长指导卡

家长配合：孩子与同学闹矛盾时，家长只做三件事——先听完（不打断）、再问“你想怎么解决”、最后把“说 sorry 和 make up”的决定权交回给孩子；周末和孩子互相听写 make up 的四个义项并各造一句，家长造的句子让孩子打分。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 义项抢答：一人报句子（make up a story 等），另一人抢答“和好/编造/组成/弥补”，10句记分；② 和好剧本：两人编一段30秒英语和解对话（必须用 make up 和 sorry），演给对方看再互换；③ 演完互评、互测通过后一起打卡，把和解金句写在对方书签上。

📝 中考考点卡 · make up (with sb)

考点1　和好义：make up with sb / They made up.（不及物用法）
考点2　一词多义辨析：编造 make up a story / 组成 make up 60% / 弥补 make up for
易错　代词宾语必须插中间：make it up ✓，❌ make up it；makeup 合写是名词“化妆品”

⚖️ 易混辨析卡 · 别再认错make up (with sb)
make up with sb ↔ make up for sth
with 接“人”（和好对象），for 接“事”（弥补的东西）
make up with her和她和好
make up for lost time弥补失去的时间
make up（和好）↔ makeup（化妆品）
分写是短语动词，合写是名词——书写时看清空格
make upv. 和好：They made up finally.
makeupn. 化妆品：She seldom wears makeup.
🔥 火眼金睛：选词填空：After the quarrel, Tom said sorry and they ______.
句意是“和好”，用 made up；made up for it 是“弥补它”，made of 是“由……制成”，都不合语境。

📖 微型故事《One Eraser, Three Days》

许诺和同桌冷战三天，起因只是一块被误拿的橡皮。周五放学，许诺在对方笔袋里塞了张纸条：新橡皮送你，旧的算我的错。周一早读，笔袋里躺着一张回条：其实早想和好了，就是拉不下脸。两人在走廊里碰面，同时伸出手，击了个掌。许诺在周记里写下金句：Making up takes one sentence; staying angry costs three days. 和好只要一句话，生气却要花三天——这笔账怎么算，都是和好划算。

🏛️ 词源故事

make 是日耳曼本土词，古英语 macian（做）；up 字面“向上”。make up 字面是“做上去/补齐”——把缺的东西补足：补故事（编造）、补份额（组成）、补脸色（化妆）、补关系（和好）。短语动词的词义像滚雪球：核心永远是“补上缺口”。和朋友 make up，就是把关系里缺的那一小块，亲手补回去——这也是它最适合出现在“沟通”单元的原因。

⚡ 冷知识

🔤 和平的经典符号——白鸽衔着橄榄枝——出自《创世纪》中诺亚方舟的故事：洪水退去，鸽子衔回一片橄榄叶，宣告“可以和好了”。从那时起，“递出点什么”就一直是人类 make up 的开场白：一块橡皮、一张纸条，都是你的橄榄枝。
