1️⃣ 五维拆解法

形·拼写honeycomb = honey + comb：一眼拆词——装蜜的“巢格”
✏️ 拼写连贯：honey与comb之间不加连字符（✗honey-comb在课本词表不分家）
音·发音/ˈhʌnikəʊm/ 三音节，重音在首音节，comb词尾b不发音
🎧 跟读：honeycomb · create honeycombs · a honeycomb cell 蜂房
意·释义n. 蜂巢——蜜蜂贮存蜂蜜的六边形蜡质结构
用·句型① In order to store honey, they create honeycombs. ② the hexagonal cells of a honeycomb ③ a piece of honeycomb 一块蜂巢
拓·同族comb n. 梳子/巢框（b不发音）· honeycomb structure 蜂巢结构（工程学借词）

📋 功能句总结 · In order to..., they create... — 目的+建造句型

目的句：In order to store honey, they create honeycombs.（建巢是为了存蜜） 复合词拆解：honey + comb = 蜂巢（先拆后记） 科普句：Each cell of the honeycomb is a hexagon. 蜂巢的每个巢房都是六边形。

📝 中考考点卡 · honeycomb

考点1　复合词拼写：honeycomb（不加分隔符），复数honeycombs
考点2　comb词尾b不发音：/ˈhʌnikəʊm/
易错　✗honey-comb → ✅honeycomb；别把comb读出/b/音

⚖️ 易混辨析卡 · 别再认错honeycomb
honeycomb ↔ comb
comb两个义项：梳子与巢框——honeycomb专指蜂巢，别把蜂巢说成“蜂蜜梳”
honeycombn. 蜂巢：bees create honeycombs
combn. 梳子：a wooden comb
honeycomb ↔ honeybee
复合词分工：巢comb，蜂bee——物件与生物各是各
honeycomb蜂巢（建筑）
honeybee蜜蜂（建筑师）
🔥 火眼金睛：选词填空：Bees create ______ in order to store honey.
蜜蜂建造的是一个个蜂巢，用复数honeycombs；honeybee是蜜蜂本蜂，建造者不是被建物。

📖 微型故事《The Perfect Answer》

科技节模型赛，覃一选了蜂巢做主题：正六边形拼起来不留缝隙，用料最省。答辩时有人问为什么不用圆形，他把纸剪的圆片、三角形和六边形摆在一起——圆片之间全是空隙，六边形严丝合缝。评委点头记下高分。他在展板上写下：The bee drew the best answer long before us. 蜜蜂早在人类之前，就画出了这道几何题的最佳答案。

🏛️ 词源故事

honeycomb是honey（蜜）+comb的复合词。这里的comb不是“梳子”那个词的今天用法——古英语里它兼指“蜂巢的蜡质部分”，与梳齿的camb拼写相同但分工明确；词源学家认为两个词在古老时代就各自独立生长，后来拼写合流。comb词尾的b从不发音——一口“哑巴b”，是英语拼写的历史包浆。

🎵 歌词里的honeycomb

⚡ 冷知识

六边形蜂巢为什么最省料？数学家猜了几百年，1999年数学家托马斯·黑尔斯正式证明“蜂巢猜想”：在所有能铺满平面的形状里，正六边形的周长总和最小——蜜蜂用了几千万年的方案，人类用数学才补上证明。
