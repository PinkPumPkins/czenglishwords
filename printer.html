1️⃣ 五维拆解法

形·拼写printer = print + er，打印的“机器”也叫“印机”
✏️ 形近：painter 画家——print 含 n（打印），paint 含 a（颜料），a 代表 art
音·发音/ˈprɪntə(r)/ 重音在首音节，/pr/ 连读
🎧 跟读：a 3D printer · print out · send it to the printer
意·释义n. 打印机；印刷公司——机器名也可指公司：出版印刷的商号在英语里也叫 printer
用·句型① The printer is out of paper. ② Please print your file out. ③ Send the file to the printer.
拓·同族print v. 打印；n. 印迹 · printing n. 印刷术 · 3D printer 3D打印机 · print 20 copies 打印20份

👨‍👩‍👧 家长指导卡

家长配合：请孩子当一周“家庭打印员”——成绩单、说明书、照片都由他用打印机输出，全程英语口令（print it out / put in paper）；卡纸时先别动手，让他用英语描述问题再解决——能把问题描述清楚的人，写作文也不缺条理。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 词族互测：print/printer/printing 三连问（词性+中文）互批；② 打印指令互发：一人用英语下指令（Print my file out, please.），另一人执行并复述，10回合记分；③ 零失误一起打卡。

📖 微型故事《Layer One 第一层》

3D打印社团领到的任务：为社区残障叔叔打印一个门把手模型。第一层塑料丝铺下去，薄得像一片纸。“这也叫把手？”有人笑。二十层，还是一块平板；六十层，隐约翘起一个弧度；四个小时后，一只弯弯的把手立在托盘上，还带着余温。社长把模型递出去时说：它的每一步都很无聊，合起来才叫作品。Nothing great looks great at layer one. 伟大的东西，没有一层就成形的。

🧑‍🏫 自测提问卡：
• 细节题：What did the club print, and how long did it take?
• 推断题：Why did some members laugh at layer one? What does “合起来才叫作品” teach about big projects?
• 迁移题（开放）：What are you building “layer by layer” this term (词汇量/体能/画技)? 用英语写两句进度报告

🏛️ 词源故事

print 的祖先是拉丁语 premere（按压）——古法语 preinte 就是“被压出的印痕”。所以“打印”的本义是“压”：活字压上纸，墨留下；喷头压出塑料丝，物体长出。printer 的后缀 -er 既能指机器也能指人——打印机与印刷公司共用一个名字，因为在英语眼里，它们都是“按东西的东西”。
