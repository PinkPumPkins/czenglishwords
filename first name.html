1️⃣ 五维拆解法

形·拼写first name = first（在前的）+ name——全名里排第一段的就是"名"
✏️ 与 last name 成对记忆：first 在前是名，last 在后是姓
音·发音/fɜːst neɪm/ first 读 /fɜːst/，长元音 /ɜː/
🎧 跟读：first name · What's his first name? · Hui is her first name
意·释义名字（= given name）——英语姓名的第一段；中文姓名里对应的"名"，位置在姓后
用·句型① Hui is her first name. ② What is the first name of Peter's class teacher? ③ May I have your first name?
拓·同族given name 名（受赠之名）· last name 姓 · first of all 首先 · first place 第一名

📋 功能句总结 · 问"名"的两种问法

问：What's your first name? / What is the first name of...? 答：My first name is Ming. / His first name is Peter. 文化点：英语国家熟人会直呼 first name；对老师仍用 Mr/Ms + 姓

👨‍👩‍👧 家长指导卡

家长配合：全家来一次"first name 茶话会"——每人讲自己名字的由来和一个含义，孩子用英语总结：My first name is..., it means...（不会的词查词典）。名字是最短的家史，也是最好写的英语作文素材。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 名字含义互换：各用英语说出自己 first name 的含义（My first name is..., it means...），对方复述并打分；② 名姓抢答：报全名，对方3秒内拆出 first name / last name，10轮记分；③ 都完成后一起打卡，并把"我的名字含义"各写一句贴在对方笔记本上。

📝 中考考点卡 · first name

考点1　first name = 名（英语姓名第一段），同义词 given name
考点2　对老师的规范称呼：Mr/Ms + last name——不能只叫 first name（课本第21页正是考这个文化点）
易错　中文姓名直译拼音：姓算 last name，名算 first name（Chen Jie：Chen 是 last name，Jie 是 first name）

⚖️ 易混辨析卡 · 别再认错first name
first name ↔ given name
同义可互换，考试认得出即可
first name口语最常用
given name更书面：受（父母）赠予之名
first name ↔ first of all
first name 是名词"名字"，first of all 是"首先"——作文开场别写混
first namen. 名字
first of alladv. 首先（引出第一点）
🔥 火眼金睛：Chen Jie 的 first name 是？
first name 指"名"：中文姓名 Chen Jie 里，Chen 是姓（last name），Jie 是名（first name）。

📖 微型故事《The Name with a Story》

英语老师让每人起一个英文名，名册贴出来那天，班上炸了锅：三个 Amy、两个 Kevin。陈默想了个办法——她在英文名后面用小字标了含义：Amy = 被爱的；Kevin = 帅气的（全班爆笑）。外教看了名册说："A first name with a meaning is easier to remember." 于是每个 Amy 都有了自己的故事。后来班里流行互相问：What does your first name mean? 一句问话，把三个重名的 Amy 问成了三个朋友。她在日记里写：A first name is small, but its story is yours forever. 名字很小，它的故事永远是你的。

🧑‍🏫 自测提问卡：
• 细节题：How many Amys and Kevins were in the class?
• 推断题：Why did writing the meaning next to each English name work so well?
• 迁移题（开放）：What does your first name mean? 用英语写两句你的"名字故事"

🗺️ 思维导图

┌── 核心 ── first name 名字（全名第一段） ├── 同义 ── given name 受赠之名 ├── 成对 ── last name 姓 · middle name 中间名 ├── 文化 ── 熟人可直呼 first name · 对老师用 Mr/Ms+姓 └── 课本 ── Hui is her first name.（第21页）

🏛️ 词源故事

first 出自古英语 fyrst，是 fore（在前）的最高级——"最靠前的"。它的近亲 foremost（首要的）、before、forward 都带着同一个"前"字根。first name 里的 first，说的是"排在最前的那一段名字"——对英语姓名来说是名，对中文姓名来说位置正好倒过来：这就是为什么 Chen Jie 的 first name 是 Jie。一个 first，藏着英语姓名的整个顺序图。

📜 名言 & 谚语
