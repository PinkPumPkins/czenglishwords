1️⃣ 五维拆解法

形·拼写object = ob（对面）+ ject（扔）→ “扔到你面前的”就是物品
✏️ 一词两读：n. /ˈɒbdʒɪkt/ 物品·宾语 ↔ v. /əbˈdʒekt/ 反对
音·发音名词重音在前 /ˈɒbdʒɪkt/，动词重音在后 /əbˈdʒekt/——重音移位是考点
🎧 跟读：a beautiful object · the object of the sentence · object to sth
意·释义n. 物品；宾语——日常与语法课双高频
用·句型① a beautiful landscape or object（课本原句）② the object of a sentence 句子的宾语 ③ object complement 宾语补足语（Grammar Focus 原句）
拓·同族ject 词根家族：project 投射/项目 · reject 拒绝 · inject 注射

📝 中考考点卡 · object

考点1　重音辨义：n. /ˈɒbdʒɪkt/ 物品·宾语 ↔ v. /əbˈdʒekt/ 反对
考点2　语法术语：object 宾语 / object complement 宾补（Grammar Focus 考向）
易错　object 作动词“反对”接介词 to：object to the plan；subject 与 object 别调换

⚖️ 易混辨析卡 · 别再认错object
object ↔ subject
形近反义：宾语 ↔ 主语（词源是“扔”与“垫”）
object宾语/物品：music is the object
subject主语/科目：I is the subject
object n. /ˈɒbdʒɪkt/ ↔ object v. /əbˈdʒekt/
重音移位：名词重音在前，动词重音在后
object n.物品；宾语：a beautiful object
object v.反对：object to the plan

👪 陪读故事 + 思维导图 + 词源小知识

📖 微型故事《The Word on the Desk》

语法课讲到“宾语”，全班睡倒一半。英语老师没喊人，只把自己的保温杯放上讲台：This is an object——它是你摸得着的东西。然后她在黑板写下 I love my cup.，圈住 my cup：love 这个动作“扔”出去，落在谁身上？教室突然安静——原来宾语不是术语，是动作的落点。下课后我发现，她保温杯上贴着一张小纸条：Objects can carry feelings, too. 物品也可以装着感情。

🗺️ 思维导图

┌── 核心 ── object n. 物品；宾语 ├── 语法链 ── subject 主语 → verb 谓语 → object 宾语 ├── 重音链 ── n. /ˈɒbdʒɪkt/ ↔ v. /əbˈdʒekt/ 反对 ├── 词根链 ── ob对面 + ject扔：project · reject · inject └── 名言 ── What’s in a name? — Shakespeare

🏛️ 词源故事

object 来自拉丁语 obiectum——ob-（对面）+ iacere（扔），字面“扔到对面、呈现在眼前的东西”。它的老对手 subject（sub- 在下面 + jacere）原义“垫在下面的”。哲学里的“主体/客体”、语法里的“主语/宾语”，都是这一对“扔”出来的。同族还有 project（向前扔→投射）、reject（扔回来→拒绝）。

⚡ 冷知识

🔤 “主体”与“客体”的词源是一场抛接球：object 是“扔到眼前之物”，subject 是“垫在底下的承受者”。中世纪哲学定下这一对概念，后来语法书借来命名主语（subject）与宾语（object）——你每分析一个句子，都在重现两千年的哲学。
