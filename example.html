1️⃣ 五维拆解法

形·拼写example 7个字母：e-x-a-m-p-l-e，一头一尾两个 e
✏️ 缩写 e.g. 就来自它的拉丁祖先；别与 sample（样品）混
音·发音/ɪɡˈzɑːmpl/ 拼写是 x，读音却是 /ɪɡ/ 不是 /eks/
🎧 跟读：for example · give an example · set an example
意·释义例子；范例——把抽象道理变成看得见的那一个
用·句型① For example, we celebrate Shakespeare's birthday as English Language Day. ② give an example 举例 ③ set a good example 树立榜样
拓·同族sample 样品（同源双胞胎）· exemplary 模范的 · for instance 例如（同义替换）

📋 功能句总结 · for example + give/set an example

👨‍👩‍👧 家长指导卡

家长配合：让孩子每周“教家长一个例句”——家长故意问 What does this word mean? Can you give an example?；孩子举不出例子时，家长示范举一个再让他换一个。会举例，才算真会一个词。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 举例接龙：一人说观点，另一人必须用 For example 接一个完整例子，接不上换人；② 搭配互测：give/set/follow + example 各说一句；③ 各自为对方写一条“榜样例句”（He/She sets an example by...），完成一起打卡。

📝 中考考点卡 · example

考点1　for example 接完整例子；such as 接名词列举
考点2　give / set an example 搭配
易错　example 开头读 /ɪɡ/ 不是 /eks/；e.g. 是书面缩写（= for example）

⚖️ 易混辨析卡 · 别再认错example
for example ↔ such as
for example 引出完整例子（可接句子）；such as 接名词列举（不接句子）
for example+ 完整例子/句子：For example, we plant a tree.
such as+ 名词列举：fruits such as apples and pears
example ↔ sample
同源双胞胎：example 例子/榜样，sample 样品（试吃试用）
examplen. 例子；范例：set an example
samplen. 样品：free samples 免费试用品
🔥 火眼金睛：选词填空：I like many sports, ______ basketball and swimming.
后面是两个并列名词的“列举”，用 such as；for example 一般引出一个完整的例子或句子。

📖 微型故事《The Shortest Sentence》

英语老师有条规矩：查词典必须抄下一个例句才算查完。吴磊嫌麻烦，专挑最短的抄。直到有一天他抄到 “He set an example for us.”，盯着看了半天才反应过来——这不就是上周他帮低年级修饮水机的事吗？从那天起，他抄例句专挑“和自己有关的”。期末盘点，他发现例句记得牢的单词一个都没忘。当你在例句里看见自己，这个词才真正属于你：A word becomes yours the day you find yourself inside its example.

🗺️ 思维导图

┌── 核心 ── example n. 例子；范例 ├── 举例链 ── for example · such as · for instance ├── 榜样链 ── set an example · a good example for sb ├── 同源 ── sample 样品 · exemplary 模范的 └── 课本 ── For example, ... Shakespeare's birthday (P71)

🏛️ 词源故事

example 源自拉丁语 exemplum“取样、样品”，词根 eximere 意为“拿出来”（ex- 出 + emere 取）——例子就是把大道理里“拿出来给人看”的那一件。它还有个失散的双胞胎：sample（样品）——同一个拉丁词，走古法语的不同路口进来，首音节磨没了。词典例句的传统也要感谢它：1755年约翰逊博士的《英语词典》就是用文学名句当例子的。链路：拉丁 exemplum → 古法语 example → 英语 example。

⚡ 冷知识
