1️⃣ 五维拆解法

形·拼写size 四字母 s-i-z-e，词尾 e 让 i 读长音 /aɪ/
✏️ 警惕：size 尺寸 ≠ side 边——中间是 z 不是 d
音·发音/saɪz/ /z/ 浊音收尾，e 不发音
🎧 跟读：size · the size of the box · What size do you want?
意·释义n. 大小；尺寸（可数）——也指尺码（衣服鞋帽）
用·句型① in size and colour ② What size...? ③ the size of a football 和足球一样大
拓·同族small/medium/large size · life-size 与实物一样大 · size up 估量

👨‍👩‍👧 家长指导卡

家长配合：换季买鞋买衣让孩子全用英语问码（What size...?），你只答 Small/Medium/Large；听写盯 size/side 听音辨形；家里量家具尺寸时让孩子报 The desk is the size of two school bags.，练“大小”的口语化表达。

📝 中考考点卡 · size

考点1　倍数表达：twice the size of...（两倍于）
考点2　问尺码：What size do you want?
易错　size /saɪz/ ≠ side /saɪd/——尾音 /z/ /d/；in size and colour 中 size 前不加冠词

⚖️ 易混辨析卡 · 别再认错size
size ↔ side
尾音之差：/saɪz/ 尺寸 vs /saɪd/ 边——z 与 d 听力分胜负
sizen. 大小；尺寸：the size of the box
siden. 边；侧：on the other side
the same size as ↔ the same as
精确与笼统：加 size 才说明“尺寸相同”
the same size as尺寸一样大：My bag is the same size as yours.
the same as和……一样（泛指）：My idea is the same as hers.
🔥 火眼金睛：单选：The new playground is twice ______ the old one.
倍数要接 the size of 结构，size 前必须有 the：twice the size of the old one。

📖 微型故事《XL and Proud》

校服换季，班里最后一件只剩加加大号XL，体育委员默默领了——他不高，但那周他每天最早到操场，空荡的袖子在风里像两面小旗。有人问他穿这么大的衣服跑什么，他说：袖子长，扇起来风大，跑得就有样子。月底校服补货到，他换回M号，把XL洗干净叠好放进失物招领箱，附纸条：给下一个最早到操场的人。Size is for the body; the spirit picks its own. 尺码管身体，精神自己选码。

🏛️ 词源故事

size 的祖先出乎意料地“官气”：它经古法语 sise（法定份量）进入英语，再往上追到拉丁语 assidere“坐在旁边”——正是 assess（评估）的源头：官员坐在货物旁边估量份量。中世纪英格兰真有《面包法令》：按价格规定面包的大小，短斤缺两要罚。所以 size 最早不是量衣服的，是量面包的——尺寸一开始就是一件讲公平的事。

⚡ 冷知识

🍞 1266年英格兰颁布《面包法令》（Assize of Bread and Ale），按价格给面包定法定重量——卖小了要罚款。这是英语世界最早的食品法规之一，也是 size 一词里“法定份量”老底的现实回声。
