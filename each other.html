1️⃣ 五维拆解法

形·拼写each + other 两个词手拉手：each 管"每一个"，other 管"另一个"
✏️ 固定短语不能拆：✗ each the other，✗ each others
音·发音/iːtʃ ˈʌðə(r)/ each 的尾音 /tʃ/ 紧接 other 的 /ʌ/，读成一组
🎧 跟读：greet each other · help each other · learn from each other
意·释义互相；彼此（代词短语）——A 对 B 做，B 对 A 也做
用·句型① Greet each other. ② We help each other with homework. ③ The two teams learn from each other.
拓·同族one another（三者以上·传统规则）· 反身代词 themselves（各自，≠ 互相）

👨‍👩‍👧 家长指导卡

家长配合：设一个"each other 时间"——每周日全家轮流用一句英语感谢另一位家人，说完击掌；家长负责计时并当第一个说的人。互相表达这件事，家里先练熟，教室才敢开口。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 三日打卡：连续3天，每天互说3句含 each other 的英语（greet/help/learn from），录音发给对方；② 改错互出题：各出2道 each others / themselves 陷阱题互测；③ 双方录音全通过才一起打卡。

📝 中考考点卡 · each other

考点1　动词搭配：greet/say hi to/help/learn from each other
考点2　each other 无复数、不作主语；两者用 each other，三者以上传统用 one another
易错　✗ each others；each other（互相）≠ themselves（各自）：They help each other. ≠ They help themselves.

⚖️ 易混辨析卡 · 别再认错each other
each other ↔ one another
传统规则：两者之间用 each other，三者以上用 one another（现代英语已通用，考试按传统）
each other两者：The two friends greet each other.
one another三者以上：The whole class greet one another.
each other ↔ themselves
互相 vs 各自：动作在两人之间用 each other，动作回到自己身上用 themselves
each otherThey help each other. 他们互相帮助
themselvesThey help themselves. 他们自助/自便（各自帮自己）
🔥 火眼金睛：哪句是对的？
each other 是固定短语，没有复数形式；each others 是经典错误，中考改错高频。

📖 微型故事《Trade Your Best》

英语课要建"互助对子"：每人抽一个搭档，一周内互相教一样东西。周航抽到英语最弱的陈朵，心里直喊亏。周一，陈朵教他折千纸鹤，周航折坏了四张纸；周三，周航教陈朵拼单词，一周拼了二十个。周五验收，老师问各有什么收获，陈朵说："I can spell twenty words." 周航说："I can fold a crane now." 全班笑翻，老师在黑板上写下：Teaching each other doubles what you know. 互相教一遍，知识就翻一倍。

🧑‍🏫 自测提问卡：
• 细节题：What did Chen Duo teach Zhou Hang, and what did he teach her?
• 推断题：Why do you think the teacher wrote that sentence on the blackboard instead of just saying it?
• 迁移题（开放）：你和小伙伴各会什么？用英语写两句 We teach each other... 的计划

🏛️ 词源故事

each other 是两个古英语词的握手：each（ǣlc，每一个）+ other（ōther，另一个）——"每一个（都对待）另一个"，16世纪前后凝固定型。1795年，语法学家林德利·默里立下规矩：两者之间用 each other，三者以上用 one another。现代英语其实早已通用，但考试仍按传统规则出题——老规矩有时比语言本身活得更久。

⚡ 冷知识

🔤 "两者用 each other，三者以上用 one another"这条规则，是1795年语法学家林德利·默里在《英语语法》里定的。有意思的是，早期大作家从没严格守过它，今天英语里两者也基本通用——但它依然是考试最爱：老规则不死，只是搬进了试卷。
