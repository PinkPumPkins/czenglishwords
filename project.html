1️⃣ 五维拆解法

形·拼写p-r-o-j-e-c-t 共7个字母：pro 在前，ject 居中，ct 收尾
✏️ 警惕形近词：project ≠ protect（保护）——中间是 j 不是 t
音·发音/ˈprɒdʒekt/ 名词重音在第一音节；作动词“投射”时重音后移 /prəˈdʒekt/
🎧 跟读：a school project · do a project · work on the project
意·释义n. 专题研究；项目——学校里的“大作业”：查资料、做海报、上台展示，一条龙
用·句型① We are doing a project on learning methods. ② work on a project ③ finish the project on time
拓·同族同根 ject（掷）家族：reject 拒绝 · inject 注入 · eject 弹出 · jet 喷气式飞机

📢 课本跟读表（含拓展句 · 拓展句已标注）

出处句子
常用搭配We are doing a project on learning methods.
常用搭配Each group works on its own project.
常用搭配The science project took us two weeks.
常用搭配They showed their project to the whole class.
📋 功能句总结 · do/work on a project + 项目流程句

开工：We are doing a project on...（我们在做一个关于……的专题研究） 推进：I'm working on the poster part. 收尾：We finished the project ahead of time.（提前完成）

👨‍👩‍👧 家长指导卡

家长配合：孩子做 project 时你的位置是“外包供应商”不是“代工车间”——提供旧杂志、纸板和去图书馆的接送；每周问一次进度（海报画到哪步了？汇报练了几遍？），并在汇报前当一次观众。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 流程抢答：一人说项目阶段（收集资料/做海报/汇报），另一人5秒内说出对应英语短语，答不出换人；② 互出单选：各自照本词考点出一道 work on 单选题考对方，答错重出一道；③ 两人各默写 project 三遍全对、互批后一起打卡。

📝 中考考点卡 · project

考点1　搭配 do a project / work on a project（从事项目）
考点2　重音切换：n. /ˈprɒdʒekt/ ↔ v. 投射 /prəˈdʒekt/
易错　拼写 project ≠ protect（保护）——中间是 j 不是 t，听力里 /dʒekt/ 与 /tekt/ 是信号

⚖️ 易混辨析卡 · 别再认错project
project /ˈprɒdʒekt/ ↔ protect /prəˈtekt/
形近音近双料：中间 j（/dʒ/）与 t（/t/）之别，一个“掷出项目”一个“护你周全”
projectn. 项目：a science project
protectv. 保护：protect your eyes
project ↔ object
同根 ject 对照：一个向前掷，一个向对面掷
projectn. 项目：a school project
objectn. 物体；v. 反对：an unknown object
🔥 火眼金睛：中考单选：—What is your group doing? —We are ______ a project on English learning.
从事某个项目用 work on；work out 是解出/算出，working to 不存在此搭配。

📖 微型故事《三张海报的分工表》

英语周项目发布会上，第三组带来的 project 讲纸张回收，海报却在上台时意外翻了页——忘了粘胶。台下笑声刚起，组长把海报按住，照常开口：“This is our project on paper recycling. And yes, glue also matters.”（胶水同样重要）笑声变成了掌声，比预想的更响。他们最后拿了第二名。散场后组长在小结里写下：A project is never one person's show. 项目从来不是一个人的独角戏——翻页的是海报，接住的是队友。

🧑‍🏫 自测提问卡：
• 细节题：What went wrong with Group 3's poster on stage?
• 推断题：Why did the audience's applause last longer than their laughter?
• 迁移题（开放）：If your group's project fails a part at the last minute, what would you say? 用英语写两句

🗺️ 思维导图

┌── 核心 ── project n. 项目；专题研究（复数 projects） ├── 流程链 ── do a project → collect information → make a poster → show it to the class ├── 搭配 ── work on · on time 按时 · ahead of time 提前 ├── 同根 ject 掷 ── reject 拒绝 · inject 注入 · eject 弹出 └── 词性切换 ── n. /ˈprɒdʒekt/ ↔ v. 投射 /prəˈdʒekt/

🏛️ 词源故事

project 来自拉丁语 proicere：pro-（向前）+ iacere（投掷），字面“向前抛出”——一个项目就是把一份计划抛进未来。同根兄弟个个是“扔”字辈：reject（掷回去→拒绝）、inject（掷进来→注射）、eject（掷出去→弹出），连 jet（喷气式飞机）也是这颗“掷”出的种子。掷得远，才叫项目。
