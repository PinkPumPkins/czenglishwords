1️⃣ 五维拆解法

形·拼写false 共5个字母：f-a-l-s-e——词尾是 -lse，别写成 falst
✏️ 反义词 true（真的）一对常客；名词 falsehood 再加 hood
音·发音/fɔːls/ 单音节，词尾 /ls/ 连读；与 fall /fɔːl/ 只差一个 s
🎧 跟读：false · a false impression · false friends
意·释义adj. 错误的；不真实的——false answer 错误答案 · false impression 错觉 · false statement 假陈述
用·句型① It could give people the false impression that I'm a rude person. ② true or false 判断题 ③ a false message 虚假消息
拓·同族falsely adv. 不实地 · falsehood n. 谎言 · fault n. 过错（同源辨析词）

📝 中考考点卡 · false

考点1　搭配 give sb a false impression（给某人错觉），课本原句高频
考点2　true or false 判断题用语；反义词 true
易错　false（假的）与 fault（过错/责任）形近义异：It's not my fault. 是“不怪我”；false 的词尾是 -lse，别写成 -lst

⚖️ 易混辨析卡 · 别再认错false
false /fɔːls/ ↔ fall /fɔːl/
音近词：词尾多一个 /s/；且两者词源无关（false 拉丁、fall 日耳曼）
falseadj. 假的：a false impression
fallv. 落下：Leaves fall in autumn.
false（假的）↔ fault（过错）
形近义异双料：false 说性质，fault 说责任
falseadj. 错误的；不真实的：a false statement
faultn. 过错；责任：It's not my fault.
🔥 火眼金睛：选词填空：true ↔ ______（反义词）
true（真的）的反义词是 false（假的）；fault 意为“过错、责任”，不是 true 的反义词。

📖 微型故事《The 90% Rumor》

班级群里疯传一张截图：英语考试将改为全考口语。你差点信了——截图做得很像官方通知。班长却先问了一句：Source? 然后打开老师公众号核对：查无此讯。他在群里贴出结论：It's a false message. Check before you share. 群里安静了几秒，转发过谣言的同学默默撤回。当晚你在日记里写：A false message travels fast, but a question stops it in one second. 谣言飞得快，一句“来源呢”就能让它当场停下。

🧑‍🏫 自测提问卡：
• 细节题：What was the screenshot about, and what question did the monitor ask first?
• 推断题：Why does one question “stop” a false message so quickly?
• 迁移题（开放）：Write your own two-sentence rule（英语）about sharing information online

🏛️ 词源故事

false 来自拉丁语 falsus，是动词 fallere（欺骗；使跌倒）的过去分词。这个词根的家族像一面镜子：fail（失败）、fault（过错）、fallacy（谬误）都是 fallere 的孩子——而英语里的 fall（跌落）却是日耳曼血统，和 false 不是一个爹。换句话说：false 的近亲不是 fall，是 fail——“骗”，最终都通向“错”。

⚡ 冷知识

🔤 语言学里有个术语叫 false friends（伪友）：两种语言里长得像、意思却差很远的词。经典案例：西班牙语 embarazada 不是“尴尬的”，而是“怀孕的”。词和词之间也会认错亲戚——这正是辨析 false 与 fault 的意义。
