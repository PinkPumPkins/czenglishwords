1️⃣ 五维拆解法

形·拼写keyboard = key + board，9个字母；同类复合词：blackboard 黑板、skateboard 滑板
✏️ 口诀：按下去就有回应的板子——从钢琴到电脑
音·发音/ˈkiːbɔːd/ key 长音 /iː/，重音第一音节；美音 /ˈkiːbɔːrd/ 卷舌
🎧 跟读：play the keyboard · the computer keyboard · keyboard player
意·释义n. 电子琴（乐器）；键盘（电脑/钢琴的键板）
用·句型① play the keyboard（键盘手 role in band）② type on the computer keyboard ③ a keyboard player joins the band
拓·同族key n. 键；钥匙；关键 · board n. 板 · keyboard player 键盘手

📋 功能句总结 · play the keyboard + 一词两义

👨‍👩‍👧 家长指导卡

家长配合：让孩子在家当“分类员”——把家里带按键的东西（电子琴、电脑、计算器、手机）拍下来，各用英语说一句 This is a keyboard / It has keys...，家长负责出难题“手机算不算 keyboard”；每周听写一次，重点盯 keyboard 双义与复合词结构。

📝 中考考点卡 · keyboard

考点1　一词两义：electronic keyboard 电子琴（乐器）/ computer keyboard 键盘（部件）——靠语境判断
考点2　play the keyboard 弹电子琴（乐器前加 the）
易错　美音 /ˈkiːbɔːrd/ 卷舌、英音不卷；key 还有“钥匙、关键”义（the key to success）

⚖️ 易混辨析卡 · 别再认错keyboard
keyboard（电子琴）↔ piano（钢琴）
同是键，发声不同：keyboard 电子发声、便携；piano 内有弦与踏板
keyboard电子琴：electronic keyboard 电子发声
piano钢琴：grand piano 三角钢琴
keyboard（键盘）↔ key（钥匙）
keyboard 里的 key 是“键”，不是“钥匙”——key 本义钥匙，引申“键、关键”
key钥匙/关键：the key to the room
keyboard键盘：type on the keyboard
🔥 火眼金睛：哪个短语里的 keyboard 指乐器？
electronic keyboard 电子琴是乐器；computer keyboard 是电脑的键盘部件。

📖 微型故事《The Quiet Librarian》

班级乐队的键盘手转学了，排练停了一周。招新海报贴出第三天，来面试的是平时话最少的图书管理员。他坐下来先弹了一段自己编的和弦，小声说：“我只在琴行旁听了一年，不敢报。”队长按下他的手背：“排练室周三周五开放，你敢来，我们就敢排。”艺术节当晚，keyboard 的声音把三首歌串成一场完整的演出。散场后他在日记本上写：The keyboard has 61 keys; courage only needs one. 电子琴有61个键，勇气只需要按下一个。

🧑‍🏫 自测提问卡：
• 细节题：Who came to the audition, and what had he done for a year?
• 推断题：Why does the writer say courage “only needs one” key?
• 迁移题（开放）：What is one thing you have wanted to try but hesitated? 用英语写两句，并写下你的“第一个键”

🏛️ 词源故事

keyboard = key + board。key 的来历至今没有可靠定论——古英语 cǣg，词源学家坦承“源头不详”；board 来自古英语 bord（木板）。两块“板”拼在一起，从钢琴到电脑，都是“按下去就有回应”的板子。类似的复合词还有 blackboard、skateboard——board 是英语造词的高产户。

⚡ 冷知识

🔤 电脑键盘上那排 QWERTY 字母来自1873年：发明家肖尔斯把打字机设计卖给雷明顿公司，这种排布随之传遍世界——流传最广的解释是为了减少相邻打字杆卡壳。
