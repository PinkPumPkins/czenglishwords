1️⃣ 五维拆解法

形·拼写used to 后接动词原形；to 是不定式符号不是介词
✏️ 大考点：used to do（过去常常）≠ be used to doing（习惯于）
音·发音/ˈjuːst tu/ used 读 /juːst/，to 常弱读 /tə/
🎧 跟读：used to get up early · I used to think... · Did you use to...?
意·释义过去常常（做某事），暗示“现在不这样了”
用·句型① I used to think it was easy. ② There used to be a small shop here. ③ Did you use to swim?
拓·同族be used to doing 习惯于 · be used to do 被用来做 · use n./v. 使用

📢 课本跟读表（含拓展句 · 拓展句已标注）

出处句子
搭配表used to do 过去常常做：I used to play basketball after school.
搭配表be used to doing 习惯于：I am used to getting up early.
搭配表be used to do 被用来做：Wood is used to make paper.
搭配表否定/疑问：I didn't use to like maths. / Did you use to swim?
📋 功能句总结 · used to 三兄弟句型

过去习惯：I used to get up late.（现在不了） 现在的习惯：I am used to getting up early.（be used to + doing） 用途：A knife is used to cut things.（be used to + do 被动）

👨‍👩‍👧 家长指导卡

家长配合：饭桌上玩“曾经-现在”接龙——每人说一句 I used to..., but now...（如 I used to be afraid of the dark, but now I sleep with lights off），说满三句才能离席；家长也必须说，并且至少一句要让全家笑。孩子在一阵大笑里就把三个 used to 分清了。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 三句快判：一人念三个句式（used to do / be used to doing / be used to do），另一人抢答中文含义，9题全对过关；② 变化互批：各自写三句 I used to..., but now...，交换检查动词是否原形、but now 后时态是否现在；③ 都通过后一起打卡，周五互查一句“本周真实变化”。

📝 中考考点卡 · used to

考点1　used to + 动词原形（过去常常，现在不再）：He used to live here.
考点2　否定/疑问借 did：Did you use to...? / I didn't use to...（此时用原形 use）
易错　used to do ≠ be used to doing（习惯于）≠ be used to do（被用来做）——中考三大易混；used 读 /juːst/

⚖️ 易混辨析卡 · 别再认错used to
used to do ↔ be used to doing
中考头号陷阱：used to + 原形 = 过去常常；be used to + doing = 习惯于
used to do过去常常：I used to swim every day.
be used to doing习惯于：I am used to getting up early.
be used to doing ↔ be used to do
to 后动词形式定含义：doing 习惯于，do 被用来
be used to doing习惯于做某事：She is used to working at night.
be used to do被用来做某事：Knives are used to cut things.
🔥 火眼金睛：选词填空：My father ______ smoke, but he gave up last year.
gave up last year 表明现在不抽了——“过去常常现在不再”用 used to + 动词原形；be used to 后接 doing。

📖 微型故事《The Seat by the Window》

转学生马一宁的作文开头只有一句：I used to sit by the window. 语文老师把它画上波浪线问：后来呢？她站起来说，原来的学校她坐在窗边，能看到梧桐树；转学后座位换到第三排，前两个星期她总走神，总觉得窗外少了点什么。直到上周小组值日，她擦第一排的窗户——玻璃亮起来的那一刻，她忽然发现新教室的窗外也有两棵树。I am used to the new window now, but I will always remember the old one. 老师在批注里写：Used to marks the past; noticing marks growth. 记住过去的是 used to，发现新的，就是长大。

🏛️ 词源故事

use 的祖先是拉丁语 uti（使用），经古法语 user 进入英语。used to 表示“过去习惯”的用法大约在18世纪定型。有趣的是，它的“前辈”是 wont——古语 “he was wont to say”（他惯常说），莎士比亚戏剧和1611年钦定版圣经里到处都是；used to 是后来居上的平民版，把文绉绉的 wont 挤出了日常口语。今天连很多母语者都不会写 wont 了，但 used to 每天被说千万次。

📜 名言 & 谚语

“Those who cannot remember the past are condemned to repeat it.” — George Santayana《The Life of Reason》(1905)（记不住过去的人注定重蹈覆辙——used to 就是用来记住过去的）

🎵 歌词里的to

🎵 The Beatles《Yesterday》(1965)：英文歌里被翻唱最多的作品之一，开头一句 “Yesterday, all my troubles seemed so far away”——讲“过去”的歌千千万，专讲“过去常常”的句式却只有一个 used to。（主题关联[过去回忆]）

⚡ 冷知识

📜 在 used to 普及之前，英语用 was wont to 表达“过去惯于”——莎士比亚戏剧和1611年钦定版圣经里常见 “he was wont to go” 这样的句子。18世纪后 used to 全面接管口语，wont 退居书面古语。一个句式的新老交替，正好被写进了文学史。
