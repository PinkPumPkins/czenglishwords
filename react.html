1️⃣ 五维拆解法

形·拼写react = re（回）+ act（做）：对刺激“做回去”的动作
✏️ 名词 reaction 只加 -ion：act → action，react → reaction
音·发音/riˈækt/ 重音后置砸在 ækt 上，re- 轻轻带过
🎧 跟读：react to the news · chemical reaction
意·释义v. 作出反应；回应：How did she react to the news? 她对这消息反应如何？
用·句型① He reacted quickly and stopped the bus. ② How did you react to the result? ③ Acids react with metals.（化学反应）
拓·同族同族：action 行动 · reaction 反应 · active 积极的 · actor 行动者

📢 课本跟读表（含拓展句 · 拓展句已标注）

出处句子
常用搭配react to sth 对某事作出反应 · react quickly/slowly 快/慢反应
常用搭配He reacted to the bad news calmly. 他平静地对这个坏消息作出了反应。
拓展（拓展）Iron reacts with oxygen in the air. 铁与空气中的氧气发生反应。
拓展（拓展）Different people react differently to the same thing. 不同的人对同一件事反应不同。
📋 功能句总结 · react to... + How did you react?

问反应：How did you react to...?（你如何反应？） 答反应：I reacted... / My reaction was...（名词形式） 固定介词：react to sth——to 不可省，也不可换

📝 中考考点卡 · react

考点1　固定介词：react to sth（❌ react sth）——How did you react to the news?
考点2　名词 reaction to...：his reaction to the plan
易错　别与 reply to（回复话语）、answer（回答问题）混淆；reacted 过去式别写成 reacteded

⚖️ 易混辨析卡 · 别再认错react
react to ↔ reply to
react 是“反应”（行为/情绪/化学），reply 是“回复”（话语）——对象不同
react to作出反应：He reacted to the news with a smile.
reply to回复（信/消息）：Please reply to my email soon.
react ↔ reach
音近词：结尾 /ækt/ 是反应，/iːtʃ/ 是到达
reactv. 反应：How did she react?
reachv. 到达：We reached the station at six.
🔥 火眼金睛：中考单选：How did you ______ the news?
对消息“作出反应”用 react to；reply 后接 to 才能接宾语（reply to the news 是回复消息），answer 不加 to。

🟡 中阶 · 家长/自学加油站
👪 陪读故事 + 思维导图 + 词源小知识

📖 微型故事《泡沫冲出瓶口的那两秒》

化学课做“火山喷发”：小苏打遇白醋。前桌伸手指向瓶口，被周老师一声喝住：“What would happen if you touched it?” 前桌缩回手，嘀咕：“只是想看看而已。”周老师没生气：“好奇心 react 对了地方，就是科学。”轮到演示，周老师故意放慢最后一步——全班屏息，泡沫涌出的瞬间，欢呼掀了屋顶。周老师趁热总结：“You can't choose what happens, but you can choose how you react.” 前桌红着脸举手：“老师，我的反应是——再也不乱伸手了。”全班大笑。

🧑‍🏫 自测提问卡：
• 细节题：What two things were mixed to make the “volcano”?
• 推断题：Why did the teacher slow down the last step on purpose?
• 迁移题（开放）：What is one thing that happened to you recently, and how did you react? 用英语说两句

🗺️ 思维导图

┌── 核心 ── react v. 作出反应（reacted / reacting） ├── 搭配链 ── react to sth · react quickly · chemical reaction ├── 词形链 ── act → action → react → reaction ├── 辨析 ── react 反应 ≠ reply 回复（reply to 是回话） └── 场景 ── 化学实验 · 突发事件 · 好坏消息

🏛️ 词源故事

react 是 re-（回）+ act（做）的合体：刺激打过来，你把动作“做回去”。act 来自拉丁 agere（行动），同一词根养出了 action（行动）、agent（代理人）、agile（敏捷的）。名词 reaction 最初是物理、化学的术语——牛顿的“作用与反作用”和实验室的“化学反应”，后来才走回人的心里：你怎么 react，就是你把“被发生的事”做成了什么。

📜 名言 & 谚语

“For every action there is an equal and opposite reaction.” — 艾萨克·牛顿《自然哲学的数学原理》(1687)（每个作用力都有一个大小相等、方向相反的反作用力——react 的物理学出处）

⚡ 冷知识

🔤 火箭在真空里没有空气可“蹬”，却照样前进——靠的正是牛顿第三定律：向后喷气（作用），自己被推向前进（反作用）。你 react 的方式，决定你去哪儿。
