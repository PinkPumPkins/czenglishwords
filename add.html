1️⃣ 五维拆解法

形·拼写a-dd：双写 d 一路保持——adding、added 都是 dd
✏️ 辨形：ad（广告）一个 d，add（添加）两个 d
音·发音/æd/ 短促有力，与 and /ænd/ 听感接近，听力会挖坑
🎧 跟读：add...to... · add up · in addition
意·释义v. 添加；加——往里放进更多：加东西、加分数、加一句备注都算
用·句型① Add one more word to each group. ② Add more things to the “other” section. ③ Add some salt to the soup.
拓·同族add up 加起来；说得通 · in addition 此外 · addition n. 加法；新增

📋 功能句总结 · add A to B（把A加进B）

加东西：Add one more word to each group. 加原料：Add some salt to the soup. 延伸：add up 加起来 — The numbers don’t add up.（数字对不上）

👨‍👩‍👧 家长指导卡

家长配合：做晚饭时给孩子发“英语配料员”工牌——每加一样料必须报 Add some... to...；最后让他总结 If you add too much salt, you can’t take it out. 厨房是最诚实的语法教室：加对了香，加多了咸，当天复盘。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 听辨对决：一人随机读 add / and，另一人举 ✓（有n）／✗（无n）牌，5局3胜；② 菜谱接龙：轮流用 Add...to... 报一步做菜动作，30秒内不断片；③ 一起打卡，断片者明早为同桌带一包饼干（正好复现本单元词）。

📝 中考考点卡 · add

考点1　add A to B：Add some salt to the soup.
考点2　祈使句用原形：Add one more word to each group.
易错　add（添加，双d）≠ ad（广告，单d）；add up 表“加起来”，口语“说得通”

⚖️ 易混辨析卡 · 别再认错add
add ↔ ad
同音不同词：/æd/ 一个是动词“添加”（双d），一个是名词“广告”（单d）
addv. 添加：Add some salt to the soup.
adn. 广告：a TV ad 电视广告
add up ↔ add up to
加起来（过程／引申）vs 总计为（结果）
add up加起来；说得通：The numbers don’t add up.
add up to总计为：The bill adds up to 58 yuan.
🔥 火眼金睛：单选：______ some hot water to the noodles.
祈使句用动词原形 Add；句首不能用三单形式 Adds。

📖 微型故事《One Spoon Too Many》

第一次给妈妈做生日面，我在“加盐”一步走了神——勺子一歪，半勺变两勺。汤咸得像海水，我急得要倒掉重来。外婆按住锅：加一坨面，卧个蛋，再添半碗清汤。十分钟后，那碗面成了，还多了个名字：浪花面。妈妈吹着热气说：会 add 的人很多，会补救的人才算出师。Life doesn’t have an “undo” button; it has a “try again” spoon. 生活没有撤销键，只有“再来一勺”。

🧑‍🏫 自测提问卡：
• 细节题：What went wrong while cooking, and how was the soup saved?
• 推断题：Why does the writer say “会补救的人才算出师”?
• 迁移题（开放）：Tell an English story about a small mistake you fixed creatively — use the word add at least once.

🗺️ 思维导图

┌── 核心 ── add v. 添加；加（added · adding） ├── 搭配链 ── add A to B · add up · add up to 总计 ├── 派生 ── addition 加法 · in addition 此外 ├── 辨析 ── add 添加 ↔ ad 广告 └── 文化 ── 加号“+”1489年首次印刷在数学书里

🏛️ 词源故事

add 的拉丁祖先 addere 由 ad（朝向）+ dare（给）拼成，字面是“给上去”。dare 这个“给”在英语里子孙满堂：data（数据——“给出的东西”）、date（日期——信上“给”的时间）、donate（捐献），都源自同一个印欧词根“给”。所以 add 的本质不是“变多”，而是“递过去”——每一次添加，都是一次给予。

⚡ 冷知识

🔤 你天天按的加号“+”，1489年才第一次被印刷出来——德国数学家约翰内斯·维德曼在商业算术书里首次使用 + 和 −。此前几千年，加法全靠字母缩写和心算口诀。一个笔画，用了五百多年没换过。
