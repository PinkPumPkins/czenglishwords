1️⃣ 五维拆解法

形·拼写if 只有两个字母：i-f，小身材大学问
✏️ 它一出场，从句动词就降级：If it rains, I'll stay.（主将从现）
音·发音/ɪf/ 短元音 /ɪ/ 开口小，别拖成长音 /iː/
🎧 跟读：if you can · What if...? · as if
意·释义conj. 如果——条件句的开关：if 引导条件从句，主句用将来时，从句用一般现在时
用·句型① Can I leave the classroom if I don't feel well? ② If it rains, we'll stay indoors. ③ What if I am late?
拓·同族if 的另一身份：“是否”（= whether）：I don't know if he will come. · as if 好像 · even if 即使

📋 功能句总结 · if 条件句：主将从现

条件：If it rains tomorrow, we'll stay at home.（主将从现） 请求许可：Can I leave the classroom if I don't feel well? “是否”：I want to know if the library is open.（= whether） 万能问句：What if...? 如果……怎么办？

👨‍👩‍👧 家长指导卡

家长配合：用“如果……就……”和孩子玩五分钟接龙——你说 If you finish dinner early,...，孩子接主句 We'll walk the dog together.，角色互换再来一轮；条件句的“主将从现”在游戏里练十遍，比做十道单选更牢，接不上的那位负责收拾碗筷。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 接龙对决：轮流说 If..., I will... 完整条件句，接不上或用了 will 在从句里的立刻输；② 两义互测：互相出句判断 if 是“如果”还是“是否”，各5句；③ 两关都过再一起打卡，输方用 If I have time..., I will... 给对方写一句下周的约定。

📝 中考考点卡 · if

考点1　if 条件句“主将从现”：If it rains, we'll stay at home.
考点2　if 表“是否”= whether（宾语从句）：I don't know if he will come.
易错　❌ If it will rain → ✅ If it rains；句中有 or not 时必须用 whether（I don't know whether or not...）

⚖️ 易混辨析卡 · 别再认错if
if（如果）↔ if（是否）
一词两义：引导条件从句是“如果”，引导宾语从句是“是否”（可与 whether 换用）
if = 如果条件句：If you are late, the teacher will ask why.
if = 是否宾语从句：I don't know if the shop is open.
🔥 火眼金睛：选词填空：If he ______ hard, he will pass the exam.
条件状语从句遵循“主将从现”：主句用 will，if 从句用一般现在时 studies。

📖 微型故事《The If List》

期中考砸的那个下午，值日生何雨在教室后墙贴了一张纸，标题是 The If List：If I check my answers twice... If I put my phone in the drawer... 十条 if，全是“如果当时”。同桌笑她马后炮，她却每天早晨在纸下补一行新的——只是把时态换成了将来：If I get up at six tomorrow, I will... 三个月后那张纸写满了，物理老师的评语只有一句：第一个把“后悔”改写成“计划”的人。An if pointing backward is regret; an if pointing forward is a plan.

🧑‍🏫 自测提问卡：
• 细节题：What was on the paper He Yu put on the wall at first?
• 推断题：Why did she change the tense from past regrets to future plans?
• 迁移题（开放）：Write your own If List — three sentences starting with If I..., I will...

🗺️ 思维导图

┌── 核心 ── if conj. 如果（条件从句开关） ├── 时态链 ── 主将从现：If it rains, I'll stay home. ├── 二义链 ── 如果（条件）≠ 是否（= whether）：I wonder if... ├── 口语链 ── What if...? 如果……怎么办 · as if 好像 · even if 即使 └── 名篇 ── Kipling《If—》· 温布尔登球场刻诗

🏛️ 词源故事

if 是古英语 gif 的直系后代，日耳曼语族的老居民。学者一直好奇它和 give（给）的相似——有一种猜测是“如果”源于“给出一个条件”的语气，但至今没有定论，词源学家也只好耸耸肩。一个小词能让词源学家认输两百年，说明它古老得连化石都懒得上岸。

📜 名言 & 谚语

“If you can keep your head when all about you are losing theirs...” — Rudyard Kipling 吉卜林《If—》(1895)（如果众人失去理智而你仍能保持清醒——英语世界最著名的“如果”）

🎵 歌词里的if

🎵 The Jackson 5《ABC》(1970)：整首歌就是一个条件句的逻辑——先给条件（坐进教室学字母），再给结果（easy as 1-2-3）。if 的语法结构，藏在节奏里。（主题关联：学校）

⚡ 冷知识

🔤 吉卜林的《If—》不仅是名篇，还是温布尔登的“守门诗”：中央球场球员入口上方刻着其中两行——If you can meet with Triumph and Disaster / And treat those two impostors just the same（如果你能坦然面对胜利与失败这两位骗子）。1995年它还被英国BBC听众评为最受欢迎的诗。连球场都在用 if 讲道理。
