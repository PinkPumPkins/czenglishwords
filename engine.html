1️⃣ 五维拆解法

形·拼写engine 的 -ine 读 /ɪn/，g 读 /dʒ/
✏️ 区分：engine 发动机 ↔ engineer 工程师——差一个后缀，差一个职业
音·发音/ˈendʒɪn/ 重音在首音节 /ˈen/
🎧 跟读：engine · start the engine · a fire engine · search engine
意·释义n. 发动机；引擎——机器的心脏，也常作比喻：大脑、热情都可以是 engine
用·句型① Start the engine, please. ② A fire engine rushed past. ③ Curiosity is the engine of learning.
拓·同族engineer n. 工程师 · fire engine 消防车 · search engine 搜索引擎 · ingenious adj. 巧妙的（同根）

👨‍👩‍👧 家长指导卡

家长配合：孩子情绪低落时，家长先别讲道理，按“发动机查油路”顺序聊三句：What happened? / When did the fuel run low? / What refuels you?——把归因从“你不行”转向“哪里缺油”。听写盯 engine/engineer 的后缀差异。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 词族对决：互出 engine/engineer/fire engine/search engine 填空五道，对多者胜；② 比喻接龙：轮流用 “... is the engine of ...” 造句，三十秒断者做一道改错；③ 各写一句“我的发动机需要什么燃料”交换互评，签名后一起打卡。

📝 中考考点卡 · engine

考点1　engine n. 发动机；start the engine 发动引擎
考点2　engineer n. 工程师（engine + -eer 从事者）——词形辨析高频
易错　a fire engine 消防车（不是“火的引擎”）；search engine 搜索引擎

⚖️ 易混辨析卡 · 别再认错engine
engine ↔ engineer
后缀定职业：engine 是机器，engineer 是造机器的人
enginen. 发动机：start the engine
engineern. 工程师：an engine engineer 发动机工程师
engine ↔ machine
engine 是提供动力的“心脏”，machine 是整台机器
engine动力装置：The engine is running.
machine整机：a washing machine 洗衣机
🔥 火眼金睛：“工程师”是______。
engineer = engine + -eer（从事者），意为工程师；engine 是发动机本身。

📖 微型故事《Check the Fuel Line First 先查油路》

航模小组的周舟负责发动机调试，可他月考排名下滑，妈妈把航模没收了。指导老师没去说情，只问了他一句：发动机一抖，你是先查油路，还是先骂发动机？周舟低头笑了。第二天他给自己排了一张“油路图”：睡前半小时刷手机，正是漏油的那根管子。他剪了。一个月后，航模回到他的桌上，月考名次也回来了。他在航模日志上写：You are the engine; check the fuel line before blaming the machine. 你自己就是那台发动机——先查油路，再怪机器。

🏛️ 词源故事

engine 的祖先拉丁语 ingenium 意为“天赋、巧思”——与 genius（天才）同一个“gen”家族。它经古法语 engin 进入英语时指“巧妙的装置”，后来才专指发动机。所以 engineer（工程师）字面是“摆弄巧思的人”；ingenious（巧妙的）与 engine 也同根——发动机的芯，本来就是一个天才点子。
