1️⃣ 五维拆解法

形·拼写save 4个字母 s-a-v-e，词尾 e 不发音
✏️ 形近音近：save /seɪv/ ↔ safe /seɪf/ ↔ sale /seɪl/——v/f/l 三兄弟
音·发音/seɪv/ 长元音 /eɪ/，三单 saves、过去式 saved
🎧 跟读：save animals · save money · save time
意·释义v. 救；储蓄；保存——save the elephants 救大象；save money 存钱；save time 省时间
用·句型① Let’s save the forests. ② How can we help save elephants? ③ Save your file before closing.
拓·同族safe adj. 安全的 · safety n. 安全 · save up 攒钱 · screensaver 屏保（“救”屏幕）

📝 中考考点卡 · save

考点1　Let’s + 动词原形（Let’s save...）
考点2　一词多义：救/存/省/保存（中考完形高频）
易错　save /seɪv/ ↔ safe /seɪf/ ↔ sale /seɪl/；save one’s life 救某人的命

⚖️ 易混辨析卡 · 别再认错save
save ↔ safe ↔ sale
三胞胎：/seɪv/ 救·存 / /seɪf/ 安全的 / /seɪl/ 出售
savev. 救；储蓄：save the elephants
safeadj. 安全的：a safe place
salen. 出售：on sale 在促销
save ↔ same
形近：save 末尾是 v+e，same 是 m+e——别把“同样的”存成“拯救”
savev. 救；储蓄
sameadj. 相同的：the same class
🔥 火眼金睛：选词填空：The doctors tried their best to ______ the boy’s life.
save one’s life 救某人的命；to 后接动词原形。

📖 微型故事《SAVE IT》

班级要办“旧书新生”图书角，预算为零。团支书陈屿在黑板上写了两个词：SAVE IT。同学们愣了——旧书怎么 save？他把主意摊开：课本留给下届、笔记扫描存档（save files）、义卖旧课外书攒班费（save money）。两周后图书角开门，扉页上贴着一句英语：Books don’t get old; they just get saved. 那学期，全班为山区小学寄去了两箱书。Save 一个词，能救动物、能存钱，也能救下一批读者的好时光。

🏛️ 词源故事

save 的两条血脉最后汇进同一条河：“救”来自古法语 sauver，“存钱”来自另一支法语 saver，都追溯到拉丁语 salvus（“安全的”）——safe、safety、salvation 都是同门。所以 save money 字面上是“把钱弄安全”：储蓄的本质，是给未来的自己兜底。

⚡ 冷知识

💾 屏保（screensaver）的“保”不是装饰：上世纪80年代的老式显示器长时间显示同一画面会被“烧”出永久残影，屏保让屏幕动起来救它。一个词见证了技术史——如今的屏幕早不怕烧，但屏保留了下来，变成了美学。
