1️⃣ 五维拆解法

形·拼写program = pro（提前）+ gram（写）——先“写”好步骤，机器才知道怎么走
✏️ 双词性 v. n.；动词过去式双写 m：programmed / programming
音·发音/ˈprəʊɡræm/ 重音在第一音节；programmer 重音移到第二音节 /prəˈɡræmə(r)/
🎧 跟读：program · a computer program · programming
意·释义v. 编写程序；n. 程序；（英式名词=programme）节目；项目——一词四义，靠语境分辨
用·句型① start programming 十岁开始编程 ② a mobile phone app 一款手机应用 ③ allow people to do sth 让人们能做某事
拓·同族programmer 程序员 · -gram 家族：telegram 电报 · diagram 图表——都是“写出来的东西”

📋 功能句总结 · program：从“写代码”到“做节目”

动词：He started programming when he was ten. / I learned to program last year. 名词：a computer program 电脑程序 · a school programme 学校项目（英式） 句型：allow sb to do sth —— His latest app allows people to find study partners.

👨‍👩‍👧 家长指导卡

家长配合：孩子对编程感兴趣时，家长不必懂代码，只需做两件事——每两周让孩子用英语演示一次他写的小程序（讲清 what it does 和 why he made it），并把演示录成小视频存档；屏幕时间谈判桌上，“能讲明白的程序”可以额外兑换半小时。

📝 中考考点卡 · program

考点1　过去式/现在分词双写 m：program → programmed → programming
考点2　allow sb to do sth：His app allows people to find study partners.
易错　英式名词拼写 programme 多个 me；computer program 一律 program；programmer 重音后移

⚖️ 易混辨析卡 · 别再认错program
program ↔ programmer ↔ programme
一个词根三个人物与两种拼写：program 是本事，programmer 是人，programme 是英式名词

programmern. 程序员：a young programmer
programmen. 节目；项目（英式）：a TV programme

📖 微型故事《The Ten-Year-Old with a Keyboard》

信息技术课自由发挥，陈默悄悄运行了自己写的第一个 program：输入同学名字，屏幕就弹出一句“今天也要加油”。有人笑他幼稚，直到考试周，全班都排着队来敲他的键盘。他在程序结尾加了一行小注释，是自己的英文：A program is a letter to the future me.（程序是写给未来自己的信。）十年后的陈默会打开它，看见今天的自己——那才是他真正想说话的人。

🧑‍🏫 自测提问卡：
• 细节题：What did Chen Mo's first program do, and who queued up to use it later?
• 推断题：Why does the writer compare a program to “a letter to the future me”?
• 迁移题（开放）：If you could write one program for your class, what would it do? 用英语写两句需求

🏛️ 词源故事

program 来自希腊语 programma：pro（提前）+ graphein（写）——“提前写好的东西”。它最早指公开张贴的告示，19世纪火车时刻表、演出单都叫 program；20世纪计算机诞生，“给机器提前写好步骤”让这个词改行做了程序。同一个 graphein：calligraphy 用笔写，photography 用光写，program 用代码写——写下来，世界才运转。

📜 名言 & 谚语

“Talk is cheap. Show me the code.” — Linus Torvalds，Linux 创始人，2000年内核邮件列表（空谈无益，拿代码来——程序员圈的实干名言）

🎵 歌词里的program

🎵 Frank Sinatra《Fly Me to the Moon》(1964)：“Fly me to the moon, let me play among the stars”——阿波罗登月时代，宇航员把这首歌带上太空作任务音乐；让飞船精确飞行的，正是指挥舱里的 program。（主题关联[太空]·单元配歌）

⚡ 冷知识

🔤 世界上第一位程序员写代码时还没有电子计算机——1843年，数学家艾达·洛夫莱斯给并未建成的分析机写下一段算法，后世公认她是第一位 programmer。1980年美国国防部把一种新语言命名为 Ada，正是向她致敬。
