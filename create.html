1️⃣ 五维拆解法

形·拼写create 重音在后：cre-ATE /kriˈeɪt/，词尾 -ate 读 /eɪt/
✏️ 别写成 creat——三个 e 一个都不能少
音·发音/kriˈeɪt/ 重音在第二音节，/eɪ/ 是双元音，读满两拍
🎧 跟读：create · created · creation · creative
意·释义v. 创造（强调“从无到有”，比 make 更郑重）——也能引申“引起”：create trouble
用·句型① People worked hard to create what we have today. ② create a new world ③ The news created a lot of problems.
拓·同族creation n. 创造；作品 · creative adj. 有创造力的 · creativity n. 创造力 · creature n. 生物（被创造之物）

📋 功能句总结 · create / make / invent 三剑客

create：从无到有地创造（艺术品、新世界、新方法）——She created a new style. make：做、制作（最普通）：make a cake / make friends invent：发明（前所未有的工具）：Edison invented the light bulb.

👨‍👩‍👧 家长指导卡

家长配合：家里设“周末创造角”——废纸箱、旧瓶盖随孩子拼装，你只当助手并追问一句英语：What did you create today? ；孩子回答后你复述一遍（You created…）帮他内化；每月把作品拍照存档，标上英文作品名。

📝 中考考点卡 · create

考点1　词形变化 create→creation→creative→creativity（中考词形转换高频）
考点2　one of + 复数名词：one of the greatest creations
易错　拼写 create 别丢 e；invent（发明工具）与 create（创造作品/条件）不可互换——Edison invented the bulb ✅，the bulb created by Edison 说成 made 不算错但弱

⚖️ 易混辨析卡 · 别再认错create
create ↔ crate
音近：create 是双音节 /kriˈeɪt/，crate 是单音节 /kreɪt/（板条箱）
createv. 创造：create a new world
craten. 板条箱：a wooden crate
create ↔ make ↔ invent
三把“造”钥匙开三把锁：郑重创造 / 普通制作 / 前所未有
create从无到有，郑重：God created the world. / create a painting
make普通制作：make a cake / make friends
invent发明新工具：Edison invented the light bulb.
🔥 火眼金睛：选词填空：Artists often ______ beauty out of ordinary things.
主语 Artists 是复数，动词用原形 create；crate 是名词“板条箱”；creates 是三单形式，与复数主语不符。

📖 微型故事《Ugly Robot, First Prize》

科技节前一天，我们组的机器人短路了，展台只剩一块空板子。林可达把接线板一摔：“全完了。”没人说话。班长忽然把彩笔拍在桌上：“那就现场造一个新的。”矿泉水瓶当轮子，旧数据线做天线，钉子当手——机器人最终丑得全班大笑，可它是我们亲手 create 出来的，还拿了创意奖。评委在展板上留了一行字：Create first, perfect later. 先创造，再完美。

🏛️ 词源故事

create 来自拉丁语 creāre（创造、生产），15世纪末经古法语进入英语。它生了一个热闹的家族：creation（作品）、creative（有创造力的）、creature（生物——字面“被创造之物”），甚至 recreation（消遣——字面“重新创造自己”，休息是把自己再造一遍）。罗马人相信创造力连着生长，词根一说与“生长”相关——拿不准就不多说，但“创造=让新东西长大”的画面感是确定无疑的。

📜 名言 & 谚语

“Creativity is just connecting things.” — Steve Jobs（《连线》杂志采访，1996）（创造力只是把东西连接起来）

🎵 歌词里的create

🎵 John Lennon《Imagine》(1971)：“Imagine all the people, sharing all the world”——想象只是第一步，把想象变成现实才叫 create。这首被传唱半个世纪的白鸽之歌，本身就是一次对和平世界的伟大创造。（补配：主题关联·创造新世界）

⚡ 冷知识

🎨 米开朗基罗1508—1512年在西斯廷礼拜堂画《创造亚当》：上帝与亚当的手指并没有碰上，画面定格在“将触未触”的瞬间——差一点点，反而是整幅画最有张力的地方。创造，往往发生在即将发生的那个瞬间。
