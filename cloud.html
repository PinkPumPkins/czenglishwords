📝 中考考点卡 · cloud

考点1　cloud n. 云（可数）：The clouds look amazing.（课本）
考点2　形容词 cloudy：It's cloudy today.
易错　谚语 Every cloud has a silver lining.（黑暗中总有一线光明）；look 后接形容词：The clouds look amazing.

⚖️ 易混辨析卡 · 别再认错cloud
cloud ↔ cloudy ↔ cloudless
名词→形容词→反义形容词
cloudn. 云：dark clouds 乌云
cloudyadj. 多云的：a cloudy day
cloudlessadj. 无云的：a cloudless sky

📖 微型故事《The Cauliflower Sky》

科学课搬到窗台边：观察云。老师发下三张卡片——卷云像羽毛，积云像花椰菜，层云像一块灰床单。全班趴在栏杆上对号入座，忽然有人喊：“那朵积云在长个儿！”十分钟后它真的长成了小山，又十分钟被风扯成棉絮。老师收卡片时说：1803年，一位叫霍华德的药剂师给云分了类，用的都是拉丁语。原来天上的云，比我们更早拥有“学名”。The sky writes and erases every day. 天空每天都在写作和擦除。

🏛️ 词源故事

cloud 的古英语 clūd 本义是“岩石堆、山丘”——那时表示“云”的词另有其人（weolcan）。因为积云圆滚滚像山包，13世纪人们把“山”借来叫云，原主反而退场。所以 cloud 的词义史是一场“鸠占鹊巢”：山挪去了天上，土块 clod 留在地上。词义会搬家，一搬就是一千年。

📜 名言 & 谚语

“Every cloud has a silver lining.” — 英语谚语（语出弥尔顿《科玛斯》1634：每朵乌云都镶着银边——黑暗中总有一线光明）

🎵 歌词里的cloud

🎵 Guns N' Roses《November Rain》(1991)：MV里那场雨中婚礼，云层低得像要塌下来——November 的云，是摇滚乐里最著名的乌云。（主题关联[天气]）

⚡ 冷知识

🔤 1803年，英国药剂师卢克·霍华德用拉丁语给云命名：cumulus（堆积）、stratus（层）、cirrus（卷）——这套分类沿用至今。他白天卖药，业余看云，看出了国际标准。
