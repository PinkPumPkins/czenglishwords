1️⃣ 五维拆解法

形·拼写so that 引导目的/结果状语从句——目的从句常配 can / could / will
✏️ 对比：so that（为了）↔ so…that…（如此……以至于），差一个空格差一个世界
音·发音/səʊ ðæt/ so 弱读 /sə/，that 弱读 /ðət/
🎧 跟读：so that · so that I could… · spoke loudly so that everyone could hear
意·释义为了；因此——Peter called Harry so that he could say sorry. 打电话“为了”道歉
用·句型① called Harry so that he could say sorry ② I got up early so that I wouldn’t be late ③ Write it down so that you won’t forget
拓·同族近义 in order that（目的）· so…that… 结果 · because 原因 · although 让步

📋 功能句总结 · so that 目的从句 — 让心意准确到达

目的：主句 + so that + 从句（常配 can / could / will / wouldn’t） 例句：He called Harry so that he could say sorry. 否定目的：…so that sb wouldn’t / won’t do… 对比：so…that…（如此…以至于）：I was so tired that I fell asleep.

👨‍👩‍👧 家长指导卡

家长配合：家庭对话里多造一个 so that——家长先示范“做一件事+目的”的表达（I put your umbrella in your bag so that you won’t get wet.），再请孩子照着说一句自己的；每周全家找三个 so that 时刻并写在便签上，攒满十张换一次周末活动——目的状语，是“把话说清楚”的第一课。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 目的/结果快判：互读含 so that 或 so…that… 的句子，对方喊“目的”或“结果”，5局3胜；② 合并句互批：各自把5组短句合并成 so that 从句并交换批改；③ 都通过才一起打卡，输的一方明天课前翻译 p29 的 so that 句。

📝 中考考点卡 · so that

考点1　so that 目的从句 + can / could / will（单选高频）
考点2　so…that…（如此…以至于）与 so that 的区分
易错　❌ He got up early so that catch the bus → ✅ …so that he could catch the bus（从句要有主语）；目的从句别用 so that + to do

⚖️ 易混辨析卡 · 别再认错so that
so that ↔ so…that…
一个空格之差：so that 表目的（为了），so…that… 表结果（如此…以至于）
so that目的：I got up early so that I wouldn’t be late.
so…that…结果：I was so tired that I fell asleep.
so that ↔ because
方向相反：so that 说“为什么做前事”，because 说“前事为什么发生”
so thatHe called Harry so that he could say sorry.（目的在前句）
becauseHe called Harry because he felt sorry.（原因在后句）
🔥 火眼金睛：选词填空：I was ______ sleepy ______ I couldn’t keep my eyes open.
“如此困以至于”是结果，用 so…that… 结构：so sleepy that…；so that 中间不能插入形容词。

📖 微型故事《The Three-Finger Gap》

科学社要给窗台的多肉做保温罩。社长把任务拆给两个人：一人量尺寸，一人算开口，so that 罩子既挡风又不闷苗。第一次成品扣上去，多肉三天就蔫了；两人翻出记录本，发现开口算小了。第二次他们留了三指宽的缝，一个冬天过去，多肉没掉一片叶。社长在结项卡上写：Design so that others can live better — that’s what engineering means.（设计的目的，是让别人活得更好——这就是工程的意思。）

🏛️ 词源故事

so 的祖先古英语 swā（如此），that 的祖先是指示词 ðæt（那个）——两个最古老的英语词拼起来，就是“为了那样”。目的从句在古英语里已有近亲（swā þæt），一千多年来一直负责回答“为什么做”。英语里功能词的词源往往朴素得惊人：最常用的词，恰恰没有华丽身世，只有最长的工作年限。

⚡ 冷知识

🔤 1868年12月，世界上第一盏交通信号灯在伦敦议会大厦外亮起——它存在 so that 行人与马车能安全错开。它是煤气灯，运行23天后因泄漏爆炸，灯的职业生涯戛然而止。今天的红绿灯已是它的第三代传人：每一次变色，都是一句 so that。
