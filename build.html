1️⃣ 五维拆解法

形·拼写build 5个字母：b-u-i-l-d，注意 u 在 i 前，词尾 -ld
✏️ 不规则变化：build–built–built；名词 building（建筑物）
音·发音/bɪld/ 单音节，词尾 /ld/ 连读顿挫
🎧 跟读：build school spirit · build a bridge · build up your body
意·释义v. 创建；建造——既造砖瓦楼桥，也造精神与信任（build school spirit）
用·句型① You have to wear a uniform because it builds school spirit. ② They built a new library last year. ③ Reading builds your vocabulary.
拓·同族build up 增强 · builder n. 建筑工人 · building n. 建筑物 · rebuild 重建

📋 功能句总结 · have to 的“为什么”结构

规则+理由：You have to wear a uniform because it builds school spirit. 结构：have to + 动词原形（客观必须）+ because + 理由 反问练习：Why do we have to...? — Because it builds...

👨‍👩‍👧 家长指导卡

家长配合：找一件“全家共建”的小工程——一起组装书架、搭阳台花架或拼一台模型，过程中家长只做助手，由孩子主持分工并全程报英语步骤（First... Then... It builds...）；完工合影时各说一句 What we build together stays together. 让 build 从单词变成共同的记忆。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 词形快判：一人随机说 build/built/building/rebuild，另一人秒答词性与中文义，10题记分；② 互批微写作：交换批改 Things Rules Build，圈出 build 的两次用法是否一次具体一次抽象；③ 互批通过一起打卡，输方明天用英语为教室提一条“共建建议”。

📝 中考考点卡 · build

考点1　不规则变化：build–built–built；被动 was/were built
考点2　抽象搭配：build school spirit / confidence / trust（建立精神、信心、信任）
易错　❌ builded；build up 强调“逐步增强”；拼写与 lend–lent、send–sent 区分

⚖️ 易混辨析卡 · 别再认错build
build ↔ built
原形与过去式只差字母位置
buildThey will build a new library.
builtThey built it in 2020. / was built 被动
build ↔ make
build 偏结构搭建，make 偏成品制造
buildbuild a bridge / build trust（造结构）
makemake a cake / make friends（出成品）
🔥 火眼金睛：选词填空：The bridge ______ in 1998 and it is still strong now.
桥是被建的，用被动语态：was built（build 的过去分词为 built）；主动语态 built 缺少 be 动词，语法不完整。

📖 微型故事《The Paper Bridge》

科技节“纸桥承重赛”，班里两组人马同时开工。一组上来就用光全部材料，桥又高又花哨，放上第一瓶水就塌了；另一组先画图，试验三角结构，给关键处留出加固位，最后纸桥稳稳承住了十二瓶矿泉水。老师在总结里写：会 build 的秘诀不在材料多，而在结构对。学习也一样——题海不是桥，方法才是。省下炫技的力气，把结构搭对，才是真功夫。

🧑‍🏫 自测提问卡：
• 细节题：How many bottles of water did the winning paper bridge hold?
• 推断题：Why do you think the first team failed although they used all their materials?
• 迁移题（开放）：What “structure” does good learning need? 用英语写两行你的“学习图纸”

🗺️ 思维导图

┌── 核心 ── build v. 建造；创建（built / built） ├── 具体链 ── build a bridge / house / road ├── 抽象链 ── build school spirit · build trust · build confidence ├── 短语 ── build up 增强 · rebuild 重建 └── 谚语 ── Rome wasn’t built in a day.

🏛️ 词源故事

build 的古英语原形 byldan，来自 bold（住所、房子）——build 的本义就是“盖房子”。一千年来它的工地越开越大：先造屋，再造桥筑城，近代以后连信心、团队、词汇量都归它“施工”。build up（逐步增强）保留着“一砖一瓦”的原始画面。罗马不是一天建成的——Rome wasn’t built in a day，这句谚语里躺着一整个词源。

📜 名言 & 谚语

“Rome wasn’t built in a day.” — 英语谚语（罗马不是一天建成的——build 的耐心）

🎵 歌词里的build

🎵 Cat Stevens《Father and Son》(1970)：父子两代人一来一回的对唱——“It’s not time to make a change”——两代人的信任，正是一句一句 build 出来的。（主题关联：成长）

⚡ 冷知识

🔤 帝国大厦1930年动工、1931年落成，只用了约410天：平均每周建四层半，钢铁工人在三百米高空递梁接柱如流水线。它至今仍是“build 得快”的传奇案例——大萧条年代的纽约，用一栋楼给自己 build 了信心。
