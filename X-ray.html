1️⃣ 五维拆解法

形·拼写X-ray 中间连字符，X 永远大写；复数 X-rays
✏️ 口诀：X 站得直（大写），杠不能丢
音·发音/ˈeksreɪ/ X 读 /eks/，整体重音在前
🎧 跟读：get an X-ray · an X-ray machine · X-rays
意·释义n. X射线检查；X射线（拍片子这件事和那种射线本身）
用·句型① You might need an X-ray.（p13原句）② You should see the dentist and get an X-ray.（p15原句）③ an X-ray of my chest
拓·同族冠词用 an（/eks/ 开头是元音音素）· X-ray machine · X光在德语叫 Röntgenstrahlen

📋 功能句总结 · get an X-ray（拍片子）

建议：You should get an X-ray. / You might need an X-ray. 结果句：The X-ray shows nothing broken.（片子显示没骨折） 冠词提醒：an X-ray（X 读 /eks/，元音开头）

📝 中考考点卡 · X-ray

考点1　get/have an X-ray（冠词 an，因 X 读 /eks/）
考点2　X-ray 复数 X-rays；作定语 an X-ray machine
易错　❌ a X-ray → ✅ an X-ray；X 必须大写；连字符别丢

⚖️ 易混辨析卡 · 别再认错X-ray
an X-ray ↔ a X-ray ✗
冠词看发音不看字母：X 读 /eks/ 是元音音素
an X-ray✅ 拍个片子
a X-ray✗ 高频错误
X-ray ↔ ray
X-ray 特指X射线/拍片；ray 泛指光线射线
X-rayn. 拍片；X射线
rayn. 光线：a ray of sunshine 一缕阳光

📖 微型故事《The Waiting Corridor》

校运会跳高决赛，最后一跳他摔在垫子边缘，手腕立刻肿起来。校医不敢大意，直接送医院拍 X-ray。走廊里他一直在想象最坏的结果，直到医生笑着说：骨头没事，软组织挫伤，休息三周。回家路上他盯着那张陌生的片子——原来自己的骨头长这样，清清楚楚，反而安心了。他在日记里写：The X-ray cannot see your fear, but it can rule it out.——片子看不见你的害怕，却能替你排除它。

🗺️ 思维导图

┌── 核心 ── X-ray n. X射线检查（an X-ray） ├── 搭配 ── get / have / take an X-ray ├── 场景 ── sports injury · dentist · chest ├── 拼写 ── X 大写 + 连字符 + 复数 X-rays └── 历史 ── 伦琴1895年发现，X=未知数

🏛️ 词源故事

X-ray 的名字是一场“数学隐喻”：1895年伦琴发现这种神秘射线时不知道它是什么，便借用数学里“未知数”的记号 X，命名为 X-Strahlen（X射线）。后来证明它是电磁波，但名字留下了。今天德语里它仍叫 Röntgenstrahlen（伦琴射线）——发现者的名字取代了“未知”，成了德国人对这位首届诺贝尔物理学奖得主的致敬。
