1️⃣ 五维拆解法

形·拼写memory 6个字母，复数 memories（y→ies）
✏️ 词族记忆法：memory 装着整个“记”的家族——memorize 背、memorial 纪念
音·发音/ˈmeməri/ 重音第一音节，与 merry /ˈmeri/（快乐的）只差一个 m
🎧 跟读：a sweet memory · create memories · in memory of
意·释义n. 回忆；记忆——可数（一段回忆）也可抽象（记忆力）
用·句型① we create memories ② What wonderful memories I have! ③ in memory of his grandmother
拓·同族memorize v. 背诵 · memorial n. 纪念碑 · remind v. 提醒（词族）

📋 功能句总结 · create memories / in memory of

动宾：create/make memories 创造回忆——we create memories 感叹句：What wonderful memories I have!（What + adj. + 复数名词） 纪念义：in memory of... 为纪念……——a photo in memory of her

📝 中考考点卡 · memory

考点1　复数 memories（y→ies）；What wonderful memories!（感叹句）
考点2　搭配 create memories / in memory of...
易错　memory（n. 记忆）↔ remind（v. 提醒）词性易混；memory /ˈmeməri/ ↔ merry /ˈmeri/ 听力陷阱

⚖️ 易混辨析卡 · 别再认错memory
remember ↔ remind
经典义近动词组：remember 自己想起，remind 是别人提醒
rememberv. 想起（自己）：I remember that day.
remindv. 提醒（他人）：The photo reminds me of her.
memory ↔ memorize
同根分工：memory 是名词（记忆），memorize 是动词（背下来）
memoryn. 回忆：a sweet memory
memorizev. 背诵：memorize the words
🔥 火眼金睛：What wonderful ______ I have of my grandmother!
感叹句 What + 形容词 + 复数名词；memory 的复数是 memories（y→ies），memorize 是动词，不能放进 What...! 句型。

📖 微型故事《The Dented Biscuit Tin》

搬家整理储物间，奶奶的旧饼干盒摔在地上，铁皮凹了一角。妈妈想扔，程小雨捡起来擦干净——盒底还留着指甲盖大的一块焦痕，那是奶奶烤焦第一炉饼干时留下的“年轮”。她把盒子放上新书架。晚上，妈妈往盒子里装了新烤的饼干，爷爷看了直点头：The box remembers. 铁盒会记得。小雨忽然懂了：memory 不是把旧物锁进柜子，而是让旧盒子重新装满新事情。

🧑‍🏫 自测提问卡：
• 细节题：What was the mark on the bottom of the biscuit tin?
• 推断题：Why does grandpa say “the box remembers”?
• 迁移题（开放）：Describe one object that carries a memory for your family. 用英语写两句

🏛️ 词源故事

memory 的祖先拉丁语 memor，本义“记得的”，更早能追到原始印欧语 *(s)mer-（记挂、惦念）。这个词根在英语里开了一整条街：memorize（背下）、memorial（纪念碑）、memoir（回忆录）、commemorate（纪念）。罗马人说 memoria 是心灵的账本——你复习单词，就是在往这本账上再记一笔。

📜 名言 & 谚语

“The past is a foreign country: they do things differently there.” — L.P. Hartley《The Go-Between》(1953)（过去是异国他乡，那里的人做事方式不同）

🎵 歌词里的memory

🎵 The Beatles《Yesterday》(1965)：史上被翻唱次数最多的歌曲之一——“Yesterday, all my troubles seemed so far away”，把“回忆”唱成了全人类的旋律。（主题关联：过去·回忆；配歌草表指定）

⚡ 冷知识

📈 1885年，德国心理学家艾宾浩斯用自己当被试，画出著名的“遗忘曲线”：新学的词一天后忘得最快，之后趋于平缓。你单词页上的“复习打卡1·2·4·7天”排期，正是按这条曲线设计的——科学地说，复习不是重复，是抢在遗忘前扶词一把。
