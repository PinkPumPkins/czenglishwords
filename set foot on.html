1️⃣ 五维拆解法

形·拼写set foot on 三词一组，foot 永远单数：不是 feet！
✏️ 场所两介词：on + 土地/星球 · in + 城市房间
音·发音/set ˈfʊt ɒn/ foot 短元音 /fʊt/，别读成 food /fuːd/
🎧 跟读：set foot on Mars · the first man to set foot on the Moon
意·释义访问；参观（某地）；踏上——文学化的“到此一游”，常与 first / never 连用
用·句型① Armstrong was the first man to set foot on the Moon. ② I've never set foot in that museum. ③ She refused to set foot on the stage.
拓·同族同义：visit（普通）· go to；foot 家族：on foot 步行 · at the foot of 在……脚下

📢 课本跟读表（含拓展句 · 拓展句已标注）

出处句子
搭配 · 登月Neil Armstrong set foot on the Moon in 1969. 阿姆斯特朗1969年踏上月球
搭配 · 初访It was the first time she had set foot in Beijing. 那是她第一次到北京
搭配 · 否定He has never set foot on a football pitch. 他从未踏上过球场
搭配 · 同族on foot 步行 · at the foot of the hill 在山脚下 · foot 短元音 /fʊt/
📋 功能句总结 · the first man to set foot on... 句型

登顶句：He was the first man to set foot on the Moon. 初访句：This is my first time setting foot in Xi'an.（set foot in + 城市） 决心句：I will set foot on Mars one day.

👨‍👩‍👧 家长指导卡

家长配合：做一张家庭“足迹地图”——把全家去过的城市钉上小旗，孩子用英语汇报：I set foot in ... in 2023。每年挑一座没去过的城市，出发前全家喊出 We'll set foot on new land tomorrow! 每周听写重点盯 foot 的单数用法与 on/in 的分工。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 足迹问答：互相问 Have you ever set foot in...? 对方用真实经历回答并追问；② 介词对决：出10个地点（星球/城市/房间），快速判断 on 还是 in；③ 双人全对后一起打卡，错的一方写五个 set foot on 的句子。

📝 中考考点卡 · set foot on

考点1　固定搭配 set foot on/in + 地点，foot 用单数
考点2　the first man to set foot on the Moon（不定式作后置定语）
易错　❌ set feet on → ✅ set foot on；on + 星球/岛屿/土地，in + 城市/房间/国家

⚖️ 易混辨析卡 · 别再认错set foot on
set foot on ↔ set foot in
on 接星球、岛屿、土地；in 接城市、房间、国家
set foot on the Moon✅ 踏上月球（星球表面）
set foot in Beijing✅ 踏进北京（城市内部）
set foot in the Moon✗ 星球表面用 on
foot ↔ feet
固定搭配里 foot 不变复数——set foot on 是“放脚”这个动作，不是“两只脚”
set foot on✅ 固定搭配
set feet on✗ 中考改错高频（feet 只用于身体部位：two feet）
🔥 火眼金睛：选词填空：Armstrong was the first man to set foot ______ the Moon.
星球表面用 on：set foot on the Moon；in 用于城市、房间等“内部”场所。

📖 微型故事《The Thirteenth Footprint 第十三个脚印》

校庆报告会来了位退休航天工程师。大屏幕放着阿波罗十一号的黑白影像，全场安静。他说：“五十年过去，踏上过月球的仍然只有那十二个人。”提问环节，初一的男生举手：“那我们这代人算什么？”全场笑了，老先生却不笑，他指着屏幕说：“算下一批。”散场时，男生在笔记本扉页写下日期和一句话：I will set my foot where only 12 have stood. 只十二人踏足之地，会有第十三个脚印——来自今天这个教室。

🧑‍🏫 自测提问卡：
• 细节题：How many people have set foot on the Moon so far, according to the engineer?
• 推断题：Why didn't the old engineer laugh at the boy's question? What did “算下一批” mean?
• 迁移题（开放）：If you were to set foot on another planet, what would be the first sentence you'd say? 用英语写出这句话

🏛️ 词源故事

set foot on 的每个零件都很老：set 来自古英语 settan（放置），foot 是古英语 fōt，一路追到原始印欧语词根 *ped-——“脚”的全人类祖先词。这条根上挂满了英语词：pedal（踏板，脚蹬的）、pedestrian（行人，用脚走的）、podium（讲台，站在“脚”上）。所以 set foot on the Moon 说到底是一句古话：把脚，放到那儿去。人类的航天梦，语法上只是一次“放置”。

📜 名言 & 谚语

“That's one small step for man, one giant leap for mankind.” — Neil Armstrong，1969年7月20日（个人一小步，人类一大步——踏上月球留下的第一个footprint）

🎵 歌词里的on

🎵 Frank Sinatra《Fly Me to the Moon》(1964)：“Let me play among the stars”——这首歌随阿波罗任务上过太空，登月舱落下的那一刻，人类真的 set foot on 了歌里唱的地方。（补配·主题关联[太空]）

⚡ 冷知识

🔤 1969–1972年间，共12人踏上过月球，此后再无一人。他们留下的脚印至今仍在——月球没有风和雨，那些footprint可能比人类文明存在得更久。第一批“访问”月球的人，签下的名字一个都还没被抹去。
