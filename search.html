1️⃣ 五维拆解法

形·拼写search 六字母 s-e-a-r-c-h，词尾 ch 读 /tʃ/
✏️ 别把 sea 和 rch 拆开记——整个词一口气
音·发音/sɜːtʃ/ 长元音 /ɜː/ 卷舌，ch 爆破
🎧 跟读：search · search for a new home · search the room
意·释义v. 寻找；搜寻（也可作名词：in search of 寻找）
用·句型① search for a new home ② search the room 搜查房间 ③ in search of 寻找（名词短语）
拓·同族searcher n. 搜寻者 · search engine 搜索引擎 · research n./v. 研究（re + search）

📋 功能句总结 · search 与 search for：搜“地方”还是搜“目标”

search + 地点：search the room 搜查这个房间 search for + 目标：search for a new home 寻找新家 合体：search the room for the key 在房间里找钥匙 名词：in search of 寻找（they set out in search of food）

👨‍👩‍👧 家长指导卡

家长配合：丢东西是天然英语课——钥匙找不到时用 We are searching for... 现场解说；听写盯 search/research 二词，re 前缀是“再搜一遍=研究”；孩子查资料时问一句 Which search engine did you use?，把词用进真实场景。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 听辨对决：search/such 混读十次打乱互测；② 方向互考：各写两句 search ___ 空格题（一处地点一处目标），交换填介词；③ 全对一起打卡，输者把 search the room for the key 句式造两句明天交。

📝 中考考点卡 · search

考点1　decide to do：decided to search for a new home
考点2　方向介词：search + 地点（搜查）；search for + 目标（寻找）
易错　search /sɜːtʃ/ ≠ such /sʌtʃ/；in search of 中 search 是名词

⚖️ 易混辨析卡 · 别再认错search
search ↔ such
音近：/sɜːtʃ/ 找 vs /sʌtʃ/ 这样的——长元音与短元音是分水岭
searchv. 搜寻：search the room
suchadj. 这样的：such a good idea
search ↔ search for
搜地点与搜目标：本单元双词条，重点辨析
search + 地点search the room 搜查这个房间
search for + 目标search for a new home 寻找新家
🔥 火眼金睛：单选：The police ______ the building but found nothing.
building 是搜查的“地点”，search 后直接接地点不用 for；found 提示过去式 searched。

👪 陪读故事 + 思维导图 + 词源小知识

📖 微型故事《The Missing Blue Notebook》

月考第二天，我的蓝皮错题本不见了——三周的心血。同桌提议全班帮忙，我们不喊不翻，只在黑板写了三个格子：见过它的人、最后位置、线索。半天后数学课代表在图表里看出规律：它总在体育课后消失。原来是前桌把相似封面的笔记本错抱走了。物归原主那天，我在扉页写下：searching teaches you where things live. 寻找教会你的，是东西住在哪里。

🧑‍🏫 自测提问卡：
• 细节题：What three boxes did the class write on the blackboard?
• 推断题：Why didn’t they just turn over everyone’s desks to look for the notebook?
• 迁移题（开放）：What is the best way to search for information before believing it? 用英语写两步

🗺️ 思维导图

┌── 核心 ── search v. 搜寻（searched / searching） ├── 方向链 ── search + 地点 搜查 · search for + 目标 寻找 ├── 词族链 ── searcher · search engine · research 研究 ├── 名词化 ── in search of 寻找 └── 文化 ── Google 的名字来自 googol（10的100次方）

🏛️ 词源故事

search 经古法语 cerchier 进入英语，拉丁源头 circare——“绕着圈走”。最初的“搜寻”是实打实的转圈排查：围场、围城、围屋。如今你在搜索框里敲回车，本质还是同一件事：绕着信息转圈，直到目标浮出来。research（研究）就是“再搜一遍”——好研究，都是不放弃的搜寻。

🎵 歌词里的search

🎵 The Coasters《Searchin’》(1957)：节奏布鲁斯经典——主唱把“寻找心上人”唱成侦探大片，Searchin’ 就是 search 的进行时。（补配：歌名含 Searchin’）

⚡ 冷知识

🔍 搜索引擎 Google 的名字来自数学词 googol——表示10的100次方，1997年创始人注册域名时把 googol 误拼成了 Google，将错就错用到现在。你想搜的东西，早在名字里就注定了要“绕圈找”。
