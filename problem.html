1️⃣ 五维拆解法

形·拼写problem 拼写 p-r-o-b-l-e-m，中间是 ble 不是 ple
✏️ 口诀：pro 在前 blem 收尾，难题见了也得退
音·发音/ˈprɒbləm/ 两个音节，重音在前，b 与 l 相邻连读
🎧 跟读：a maths problem · work out the problem · No problem!
意·释义n. 难题；困难（数学题、生活难题都叫 problem）
用·句型① work out maths problems ② have a problem with... 在……上有困难 ③ —Sorry! —No problem. 没关系
拓·同族辨析：problem 待解决的难题 ≠ question 等待回答的问题 · solve / work out a problem

📋 功能句总结 · problem 三大场景

学习场景：work out / solve a maths problem 解出数学题 求助场景：I have a problem with... 我在……上有困难 回应场景：—Sorry! —No problem. 没关系！（口语高频）

👨‍👩‍👧 家长指导卡

家长配合：家里设一面“问题墙”——每周全家各自贴一张纸条，用中英写下一个当周没解决的难题；周末一起看：解决了的划掉，解决不了的留着。让孩子看到：大人的 problem 也不少，敢写出来就赢了一半。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 搭配速配：一人报名词（problem / question / maths / letter），另一人3秒内配对动词（solve / answer / work out / reply to），10局7胜；② 难题互托：各自用英语说一个当周真难题（I have a problem with...），对方必须给出一个建议句（You can...）；③ 建议被采纳的人有权在对方复习卡上打卡。

📝 中考考点卡 · problem

考点1　动词搭配：solve / work out + problem；answer + question
考点2　口语 No problem!（回应道歉/感谢/请求）
易错　❌ answer the problem → ✅ solve the problem；拼写别写成 promblem

⚖️ 易混辨析卡 · 别再认错problem
problem ↔ question
义近陷阱：problem 是待解决的“难题”，question 是待回答的“提问”
problemn. 难题：work out a maths problem
questionn. 提问：answer the teacher’s question
No problem! ↔ You’re welcome.
回应“谢谢”的两种说法，前者更口语
No problem!没事儿（回应感谢/道歉）
You’re welcome.不客气（更标准）
🔥 火眼金睛：选词填空：—Sorry, I broke your ruler. —______.
回应道歉用 No problem!（没关系），口语高频；solve 是“解决”，不合语境。

📖 微型故事《The Problem Wall》

开学第二周，教室后墙多了一栏“Problem Wall”——每人匿名贴一个当周没解决的难题。小睿贴的是：“I hate maths problems. 我讨厌数学题。”周五清点，他的纸条下面长出七条回帖：有写“我也是”的，有抄解法口诀的，还有一条写着“我以前也讨厌，直到把它拆成三步”。期末拆墙那天，小睿把那张纸条揭下来带回了家。A problem spoken out is already half solved. 说出口的难题，已经解决了一半。

🧑‍🏫 自测提问卡：
• 细节题：What did Rui post on the Problem Wall, and how many replies did he get?
• 推断题：Why does the writer say the problem was “already half solved” once it was posted?
• 迁移题（开放）：What is your biggest problem in study right now? 用英语写一句，再写一步你打算做的尝试

🏛️ 词源故事

problem 来自希腊语 proballein——pro-（向前）+ ballein（投掷），本义“被扔到面前的东西”。难题就是被命运扔到你面前的球：你可以躲，可以喊冤，但最帅的接法是稳稳接住再抛回去。同一个 ballein 还生出了 symbol（符号，“一起投出的信物”）、parable（比喻）和 ballistic（弹道的）。下次面对 problem，记得你是在接球。

📜 名言 & 谚语

“A problem well stated is a problem half solved.” — Charles Kettering（美国发明家凯特林：把问题说清楚，问题就解决了一半）

🎵 歌词里的problem

🎵 The Jackson 5《ABC》(1970)：把学习唱成 “easy as 1-2-3”——任何 problem 拆到足够小，都会变简单。这首歌本身就是证据：复杂的灵魂乐，拆成了字母表。（主题关联：难题变小）

⚡ 冷知识

🔤 三阶魔方有43,252,003,274,489,856,000种状态（约4300亿亿种），但2010年数学家用计算机穷举证明：任意打乱的魔方，最多20步就能复原——这就是“神的数字”。再乱的问题，也有限定的最短路径。
