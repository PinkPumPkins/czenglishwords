1️⃣ 五维拆解法

形·拼写pull 四个字母：p-u-l-l，双写 l 收尾
✏️ 口诀：拉东西要“拉”到底，两个 l 拉住不放
音·发音/pʊl/ 短元音 /ʊ/（对比 pool /puːl/ 长音“泳池”）
🎧 跟读：pull the luggage · pull up · pull the door
意·释义v. & n. 拉；拖；拽——与 push（推）相反；名词还有“引力”义：the pull of home 家的引力
用·句型① pull the heavy luggage ② Pull the door, don't push. ③ the pull of the sea
拓·同族push v. 推（反义）· drag 拖（重物拖行）· pull up 停下 · pull down 拆掉

📋 功能句总结 · help sb do sth + pull

帮忙句型：Grandpa helped us pull the luggage.（help sb do sth） 操作指引：Pull the door / Push the button. 反义对照：pull 拉 ↔ push 推——商场门上天天见

👨‍👩‍👧 家长指导卡

家长配合：进出商场时玩“门语挑战”——看到门的推拉标识请孩子用英语判断（Push or pull?），答对由家长记1分，全家月底兑一次“英语小奖”；生活里的反义词这样记最牢。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 听辨对决：互读 pull/pool 各5次，另一人写 P（pull）/PP（pool），全对换攻防；② 反义互演：一人发指令（Pull/Push the door），另一人判断并英语复述，角色互换；③ 都完成才一起打卡。

📝 中考考点卡 · pull

考点1　help sb (to) do sth：helped us pull（❌ helped us to pulling）
考点2　pull 与 push 反义（阅读指示牌高频）
易错　pull /pʊl/ 短音 ≠ pool /puːl/ 泳池——听力元音长短陷阱

⚖️ 易混辨析卡 · 别再认错pull
pull /pʊl/ ↔ pool /puːl/
音近：短 /ʊ/ ↔ 长 /uː/，词义天差地别
pullv. 拉：Pull the door, please.
pooln. 泳池：swimming pool 游泳池
pull ↔ push
反义：门上的 Pull（拉）/Push（推）
pull拉；拽
push推；按
🔥 火眼金睛：The door says “PULL”, so you should ______ it open.
标识 PULL 表示“拉”，与 push（推）相反。

📖 微型故事《Grandpa's Rope》

搬进新楼那天，最沉的纸箱是爷爷的旧字典。八(2)班的孙小舟和爸爸抬到三楼就抬不动了。爷爷从工具箱抽出一根旧麻绳，套住纸箱：“Pull together — 一、二！”两个人把绳子绷直，箱子在楼道里一格一格往上挪。到五楼时掌心通红，爷爷却先给两只手吹气：“1958年我从村里往镇上拉粮食，用的也是这根绳。”金句：What pulls a family uphill is never the rope — it is the hands that hold it.（把一家人拉上坡的从来不是绳子，是握绳的手。）

🧑‍🏫 自测提问卡：
• 细节题：What was the heaviest box, and what tool did Grandpa use?
• 推断题：Why do you think Grandpa told the story of 1958 while they were pulling?
• 迁移题（开放）：Describe in English one time your family “pulled together”. What did you pull, and how?

🗺️ 思维导图

┌── 核心 ── pull v.& n. 拉；拖；拽（过去式 pulled） ├── 场景链 ── pull the luggage · pull the door · pull a cart ├── 短语链 ── pull up 停下 · pull down 拆掉 · pull together 齐心 ├── 反义 ── push 推（门上的 Push/Pull） └── 比喻 ── the pull of home 家的引力

🏛️ 词源故事

pull 是地道的中古英语词，祖先可追到日耳曼语的“拔、扯”一族（同族的低地德语里有“揪、拔”的亲戚）；与它意思相仿的 drag 却来自古诺尔斯语——北欧人带来“拖行”，本土人自家用“拉拽”。英语词汇的双层结构再次上演：北欧血统的 drag 与本土血统的 pull 一推一拉，撑起了“用力移动物体”的整个词场。

🎵 歌词里的pull

🎵 Sister Sledge《We Are Family》(1979)：拔河、搬家、抬箱子——“We are family” 唱的就是 pull together 的时刻。（主题关联[家]）

⚡ 冷知识

🔤 拔河（tug of war）曾是奥运会正式项目：1900-1920年间连续五届入奥，1920年安特卫普奥运会后退出。如今它回归校园运动会——那根绳子两端，站着人类最古老的 pull。
