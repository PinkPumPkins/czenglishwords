1️⃣ 五维拆解法

形·拼写短语动词 run after；running 双写 n——run 重读闭音节，加 -ing/-ed 双写尾辅音
✏️ 警惕：runing ✗ → running ✓
音·发音/rʌn ˈɑːftə(r)/ run 与 after 连读；美音 after 带卷舌
🎧 跟读：He is running after his hat. · run after the bus
意·释义追逐——追人、追动物、追帽子；引申“追求”（名次、梦想都追得上）
用·句型① He is shouting and (run) after his hat!（P47原文）② The dog is running after the cat. ③ run after the first place 追求第一名
拓·同族run away 逃跑 · look after 照顾 · run out of 用完——三个“邻居”别串门

👨‍👩‍👧 家长指导卡

家长配合：晨跑或接孩子放学的路上聊“追过什么”——追公交、追小狗、追答卷，用 Did you run after…? 开头让孩子复述；把 run after（追）和 look after（照顾）写成两张卡片贴在冰箱上，每天随机抽一张，请孩子用英语讲一个场景。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 短语三选一：一人读句子（追狗/照顾妹妹/逃出教室），另一人选 run after / look after / run away，8题对6题过关；② 进行时互测：互相听写 He is running after the bus.，专盯 running 双写；③ 一起打卡，败方明早要用 run after 造一个自嘲句发到学习群——追不上知识点，就追着问同学。

📝 中考考点卡 · run after

考点1　run after sb/sth 追逐：He is running after his hat.
考点2　running 双写 n（重读闭音节 +ing/-ed 双写）：running / running after
易错　run after（追）≠ look after（照顾）≠ run away（逃跑）——三个短语完形填空高频；不要漏写 after

⚖️ 易混辨析卡 · 别再认错run after
run after ↔ look after ↔ run away
长得像，意思天差地别：追／照顾／逃跑——完形填空三兄弟
run after追逐：run after the bus 追公交
look after照顾：look after my little sister
run away逃跑：The cat ran away.
🔥 火眼金睛：选择：Look! The dog is ______ after the cat.
现在进行时用 is + running；run 是重读闭音节，加 -ing 要双写 n。

📖 微型故事《Papers in the Wind》

大风天的课间，英语课代表抱着一沓听写纸穿过操场，一阵风把整沓纸掀上了天。男生们满场 run after 纸片，像课本里那个追帽子的人。班里最沉默的学习委员没有追，她弯腰捡起脚边唯一落定的那张，拍了拍土，交还老师。老师在课上说起这件事：You can't chase every page the wind takes; hold on to what it cannot take.（风带走的追不全，抓得住的别松手。）我们笑了很久，又安静了很久。

🧑‍🏫 自测提问卡：
• 细节题：What did the wind blow away, and what did the quiet student do?
• 推断题：Why did the English teacher say “hold on to what it cannot take”?
• 迁移题（开放）：What has the wind taken from you that you stopped chasing? 用英语说说你的答案

🏛️ 词源故事

run 的祖先古英语 rinnan／iernan（奔、流），词源学家把它追溯到原始印欧语词根 *rei-（流动）。所以在英语里，河水会“跑”（the river runs），鼻子会“跑”（nose runs，流鼻涕），颜色也会“跑”（colors run，掉色）——人快走是 run，水快走也是 run。run after 则给这个“流动的动词”加上方向：after 是“跟在后面”，追，就是让自己的流动方向对准目标。

📜 名言 & 谚语

“He can run, but he can't hide.” — 拳王乔·路易斯，1946年赛前谈对手（他跑得了，却藏不了——英语里最著名的一场“追逐”）

🎵 歌词里的after

🎵 Guns N' Roses《November Rain》(1991)：MV里那场追不回的婚礼暴雨教人明白——有些东西 run after 也没用，比如十一月的天，比如过去的时间；能追上的只有此刻。（主题关联[天气]）

⚡ 冷知识

🔤 《牛津英语词典》2011年大修订时，动词 run 一口气收录645个义项，成为词典里最长的动词条目——追人、追公交、追帽子、发动机空转、梯子搭在墙上……全都叫 run。一个“追”，英语给你准备了645种追法。
