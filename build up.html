1️⃣ 五维拆解法

形·拼写build + up：过去式 built up（build 不规则：build→built→built）
✏️ 易错：build 的过去分词是 built，不是 builded
音·发音/bɪld ʌp/ 短促有力，d 与 ʌ 顺势连读
🎧 跟读：build up your vocabulary · build it up（代词夹心）· build up confidence
意·释义增加；加强；创建——像盖楼一样一层层“垒”起来：词汇、信心、体力都适用
用·句型① Read more to build up your vocabulary. ② build up confidence ③ 代词夹心：build it up
拓·同族build 家族：builder 建筑工人 · building 建筑物 · rebuild 重建

👨‍👩‍👧 家长指导卡

家长配合：在家里设一面“积累墙”——孩子每背完10个词就贴一枚便利贴成塔，两个月后拍照对比；你负责递便利贴和说“又高了一层”，把 build up 变成看得见的墙。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 塔楼挑战：轮流用 build up 说一个可以“垒”的东西（vocabulary / confidence / muscle...），说不出或重复者出局；② 时态互测：互听 build / built 各三遍判断时态；③ 两人各写一句 build it up（代词夹心）、互批后一起打卡。

📝 中考考点卡 · build up

考点1　build 的不规则变化 build→built→built；❌ builded
考点2　搭配 build up your vocabulary/confidence；代词夹心 build it up
易错　辨析 build up（逐步积累）↔ set up（建立组织）↔ put up（张贴/搭建）

⚖️ 易混辨析卡 · 别再认错build up
build ↔ built
形近：尾音 /d/ 与 /t/ 是现在与过去的分界线
buildv. 建造（原形）：They build houses.
built过去式/过去分词：He built it last year.
build up ↔ set up
义近分工：set up 像剪彩，build up 像垒砖
build up逐步积累：build up your vocabulary
set up（一次性）建立：set up a club
🔥 火眼金睛：中考单选：Keep reading, and you will ______ a large vocabulary.
积累词汇量用 build up；set up 建立机构，put up 张贴/举起，均不合语境。

📖 微型故事《便利贴塔》

教室后墙的“积累塔”是英语课代表苏芮的主意：每人每背十个词贴一枚便利贴，错一背就抽走一枚。开学两个月，塔长到一米多高，也塌过两次——有同学一次贴了三十枚，第二天忘了二十个。苏芮把塌掉的塔拍照贴在旁边：“塔不是贴出来的，是垒出来的。”期末墙上有两座塔：左边崭新的很高，右边补过三次的略矮。老师指着右边那座说：“Build up means build it up again. 积累的真正动作，是再来一次。”

🧑‍🏫 自测提问卡：
• 细节题：What was the rule of the “vocabulary tower”?
• 推断题：Why did the teacher point at the tower that had collapsed three times?
• 迁移题（开放）：What will you do to build up your vocabulary this month? 用英语写两句

🗺️ 思维导图

┌── 核心 ── build up 增加；加强（built up，代词夹心 build it up） ├── 搭配链 ── build up vocabulary → confidence → strength ├── 辨析 ── build up 逐步积累 ↔ set up 建立 ↔ put up 张贴 ├── build 家族 ── builder · building · rebuild └── 节奏 ── 少量多次，塌了再垒

🏛️ 词源故事

build 的古英语祖先 byldan，本义专指“盖房子”——它的词源更早与 bold（居所、房屋）相连。后来“造房”的动词长出了比喻的手臂：造词汇、造信心、造国家都能用它。build up 里那个 up 是方向指示：一层层向上垒。盖楼的耐心，就是积累的全部秘密。
