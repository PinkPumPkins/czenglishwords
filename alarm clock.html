1️⃣ 五维拆解法

形·拼写alarm clock 复合名词：alarm（警报）+ clock（钟）——会报警的钟
✏️ 复数变词尾：two alarm clocks
音·发音/əˈlɑːm klɒk/ alarm 轻读、clock 重读
🎧 跟读：my alarm clock · set the alarm clock · the alarm clock goes off
意·释义n. 闹钟——早上叫醒你的那台钟；o’clock 只表“……点钟”，两者毫无血缘
用·句型① My alarm clock didn’t go off. ② I set my alarm clock for six. ③ a digital alarm clock 电子闹钟
拓·同族clock 家族：o’clock ……点钟 · wall clock 挂钟 · biological clock 生物钟

拓展（拓展）I set my alarm clock for six every morning. 我每天把闹钟定在六点。
拓展（拓展）My alarm clock is too quiet to wake me up. 我的闹钟太小声，叫不醒我。
📋 功能句总结 · set... for + 时间 句型

设定：I set my alarm clock for six (o’clock).（定到六点） 响起：The alarm clock went off at six. 问答：—Did your alarm clock go off? —No, so I was late.

👨‍👩‍👧 家长指导卡

家长配合：把“叫早”这件事正式移交——请孩子自己 set the alarm clock for six，家长从明早起不再敲门；他若赖床迟到，让他自己用英语向老师说明 My alarm clock didn’t go off，并承担自然结果。移交叫早权，就是移交早晨。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 搭配互测：set... for / go off / wake up 三组中英互考，错一换重背；② 情景互演：一人演闹钟没响的迟到者、一人演班主任，60秒英语对话必须出现 alarm clock didn’t go off；③ 双人互评后一起打卡，迟到戏演得越真实越好。

📝 中考考点卡 · alarm clock

考点1　set the alarm clock for + 时间点（for six 定到六点）
考点2　alarm clock goes off 闹钟响（go off＝响起）
易错　alarm clock 与 o’clock 都含 clock，但 o’clock 表“点钟”（at six o’clock），不能互换；复数 clocks

⚖️ 易混辨析卡 · 别再认错alarm clock
alarm clock ↔ o’clock
长得像、分工不同：alarm clock 是名词“闹钟”，o’clock 是副词“……点钟”，不能互换
alarm clockn. 闹钟：My alarm clock didn’t go off.
o’clockadv. 点钟：I get up at six o’clock.
go off ↔ wake up
闹钟 go off（响）是因，人 wake up（醒）是果——主语一钟一人
go offThe alarm clock went off at six.
wake upI woke up late this morning.
🔥 火眼金睛：选词填空：I get up at six ______ every day.
表“六点钟”用 six o’clock；alarm clock 是闹钟这台机器，不能填在时间点后面。

📖 微型故事《The Three Alarm Clocks》

军训前夜，方远一下设了三个闹钟：五点半、五点四十、五点五十，间隔像保险丝。第一晚，前两个响了他都没动，第三个才把他从梦里拽出来——集合迟到一分钟，全排加练两圈。第二晚他只设一个，五点半，铃声一响立刻坐起。班长问他秘诀，他说：Three alarm clocks mean I plan to fail twice. One means I plan to get up. 三个闹钟是给失败准备的；一个，是给起床准备的。

🧑‍🏫 自测提问卡：
• 细节题：How many alarm clocks did Fang Yuan set on the first night, and at what times?
• 推断题：Why did he use only one alarm clock on the second night?
• 迁移题（开放）：用英语写你的早起方案：What time do you set your alarm clock for, and what do you do when it goes off?

🏛️ 词源故事

alarm 本是古意大利语战场喊声 all’arme（拿起武器），clock 来自中世纪拉丁语 clocca（钟），很可能源自凯尔特人对钟声“咔啦咔啦”的模仿——拟声词走遍欧洲。两个词捏在一起，alarm clock 的字面就是“会喊拿武器的钟”——每个赖床的早晨，它都在向你单独下发战斗警报。

🎵 歌词里的clock

🎵 Green Day《Wake Me Up When September Ends》(2005)：绿日乐队名曲，歌名本身就是一张“叫醒申请单”。闹钟叫醒的是身体，音乐叫醒的是九月结束前的那些心事。（补配 · 同曲复用：alarm 的叫醒主题）

⚡ 冷知识

🔤 1847年，法国发明家安托万·勒迪耶拿到第一项可调时间的机械闹钟专利——在那之前，闹钟只会固定时刻响（比如哈钦斯那台凌晨4点）。你随手把闹钟定到五点半的自由，只有不到两百年历史。
