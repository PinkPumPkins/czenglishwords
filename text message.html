1️⃣ 五维拆解法

形·拼写text + message 两个词合成一个名词：文本+消息=短信
✏️ 警惕形近：message 信息 ≠ massage 按摩——只差一个 a，意思差十万八千里
音·发音/ˈtekst ˌmesɪdʒ/ text 读 /tekst/，词尾 -st 三连辅音要读全
🎧 跟读：send text messages · text message · text sb 发短信
意·释义n. （手机）短信息；短信；作动词时 text 指“给……发短信”（词表另含其他义项，以教材为准）
用·句型① send text messages ② reply to a text message ③ Text me when you get home. 到家发条短信
拓·同族message n. 消息 · text v./n. 文本；发短信 · texter 发短信的人

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 短信互译：各自写3条英语短信（含 send/reply to a text message），交换批改，重点盯 message 拼写；② 听辨积分：读 message/massage 十次打乱顺序，对方记录，错一次扣一分；③ 互批无误后在对方页面打卡——发条真实的英语短信给同桌作为打卡证据。

📝 中考考点卡 · text message

考点1　send sb a text message / send a text message to sb（双写法都考）
考点2　text 作动词：text sb = send a text message to sb
易错　message /ˈmesɪdʒ/ ≠ massage /məˈsɑːʒ/（按摩）——听力拼写双陷阱；❌ a message s → message 无双写 s

⚖️ 易混辨析卡 · 别再认错text message
message /ˈmesɪdʒ/ ↔ massage /məˈsɑːʒ/
形近音近双料陷阱：一个 a 之差，从“信息”变成“按摩”
messagen. 信息：send me a message
massagen./v. 按摩：a foot massage
send ↔ reply to
发与回方向相反：send 发出，reply to 回复（reply 后必须有 to）
send a text message发短信：I’ll send you one.
reply to a text message回短信：Did you reply to it?
🔥 火眼金睛：选出正确的句子：
message 信息；massage 是“按摩”；可数名词单数前不能没有限定词，所以 a messages 也是错的。

📖 微型故事《Count Me In》

周五晚上，姜宇盯着手机打了又删：想邀请转学走的同桌回来参加篮球赛，又怕发出去石沉大海。他把两百字的长信缩成一条 text message：Missing you. Game on Saturday? 半小时后，屏幕亮了：Count me in. 原来短信不怕短，怕的是不发。他在周记里写下金句：A short text message can carry a long friendship. 一条短信可以很短，装下的友谊却很长。周六赛场边，那个熟悉的身影朝他挥手——比任何表情包都真实。

🏛️ 词源故事

text 的祖先拉丁语 textus 本义是“织物”，来自动词 texere（编织）——英语的 textile（纺织品）与它同根。古罗马人把“写好的文章”叫 text，是因为文章像布一样由词“织”出来。所以 message 前面加上 text，字面就是“一段织好的小布条”——短短几十个字，也是你亲手织出来的信息。message 本身来自拉丁语 mittere（送出），直译“被送出去的东西”。

⚡ 冷知识

🔤 1992年12月3日，英国工程师 Neil Papworth 用电脑发出了人类第一条手机短信：Merry Christmas。更妙的是，收信人当时根本没法回复——因为那时的手机还没有键盘。今天你随手发出的一条 text message，起点只是一句圣诞祝福。
