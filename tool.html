1️⃣ 五维拆解法

形·拼写tool 4个字母：t-o-o-l，双o读长音/tuːl/
✏️ 口诀：两根手指（oo）握住工具柄
音·发音/tuːl/ 长元音/uː/拉满，词尾l轻抵上颚
🎧 跟读：a tool · make tools · tools and instruments
意·释义n. 工具；手段——干活用的器具，也指达成目的的方法
用·句型① make tools 制造工具 ② People can use it to build houses. ③ tools and instruments 工具和器械
拓·同族tool/instrument/equipment辨析 · toolbox工具箱 · 复数tools

📝 中考考点卡 · tool

考点1　use sth to do sth：use bamboo to build houses（to不定式表用途）
考点2　词义辨析：tool手工工具，instrument乐器/精密仪器，equipment不可数
易错　tool /tuːl/与pool /puːl/音近——首辅音/t/与/p/不同

⚖️ 易混辨析卡 · 别再认错tool
tool ↔ pool
首音之差：/t/ool是工具，/p/ool是水池
tooln. 工具：make tools
pooln. 游泳池：swim in the pool
tool ↔ instrument ↔ equipment
颗粒度阶梯：tool手持小工具，instrument精密或乐器，equipment成套不可数
tool扳手、锤子这类
instrument小提琴、显微镜
equipment成套设备（不可数）
🔥 火眼金睛：选词填空：The musician plays a beautiful ______ on stage.
乐器用instrument；tool指手工工具，equipment是不可数名词，前面不能加a。

📖 微型故事《Let the Tool Work》

劳动课请来修车师傅教补胎。有人徒手抠轮胎，指甲都白了，胎口纹丝不动。师傅递过撬棒：『别跟轮胎较劲，让tool替你使劲。』撬棒一插一压，胎口乖乖让开，全组都看呆了。修完后师傅擦着手说：『工具不神秘，它就是人的力气换了种用法——力气用错地方，再好的工具也是废铁。』小组长在劳动总结里写：A good tool doubles your hands——好工具，能把一双手用成两双手。

🧑‍🏫 自测提问卡：
• 细节题：What did the students fail to do with bare hands?
• 推断题：What does 'let the tool work for you' mean beyond fixing tyres?
• 迁移题（开放）：Name one 'tool' (not a physical one) that helps you study, and explain in English how you use it.

🏛️ 词源故事

tool的祖先是古英语tōl，与古诺尔斯语tól同源，本义与『制作、备料』相关——工具就是『备好了用来造东西的东西』。它在英语里很早就有比喻用法：the tools of the trade（行业家伙什儿）、a tool of policy（政策的工具）。认识tool近千年，它的定义没变过：放大人手的那段杠杆。

📜 名言 & 谚语

“If the only tool you have is a hammer, it is tempting to treat everything as if it were a nail.” — Abraham Maslow《The Psychology of Science》(1966)（手里只有锤子，看什么都像钉子——工具决定你看世界的方式）

🎵 歌词里的tool

🎵 Trini Lopez《If I Had a Hammer》(1963)：“If I had a hammer, I'd hammer in the morning”——一首把『工具』唱成正义号角的民谣，红遍当年的美国榜单。（补配 · 主题关联：工具）

⚡ 冷知识

🔤 工具不是人类的专利。1960年，26岁的珍·古道尔在坦桑尼亚冈比观察到黑猩猩把草茎修整后伸进白蚁洞『钓』白蚁。她的导师、人类学家利基回电：“我们现在必须重新定义‘工具’、重新定义‘人类’，或者承认黑猩猩也算人。”这一幕成了科学史名场面。
