1️⃣ 五维拆解法

形·拼写link 4个字母 l-i-n-k，词尾 n+k 连读成 /ŋk/
✏️ 形近警报：link（联系）≠ line（线；行）——一个连成环，一个拉成线
音·发音/lɪŋk/ 短促有力；/ɪ/ 是短音别拉长
🎧 跟读：a link between · link A with B · a rail link
意·释义n. 交通路线；联系 · v. 连接——本单元语境多为“交通连线/两地联系”
用·句型① The new bridge links the two cities. ② There is a close link between sleep and memory. ③ Click the link to watch the video.
拓·同族network（网络）= net + work 的“连环”；linked / connected 近义互换

📢 课本跟读表（含拓展句 · 拓展句已标注）

出处句子
常用搭配（拓展）link A to/with B 连接A和B · a link between A and B · a rail link 铁路连线
高频句型（拓展）The new bridge links the two cities. 新桥连接起两座城。
拓展（拓展）Scientists found a link between sleep and memory. 科学家发现睡眠与记忆之间的联系。
📋 功能句总结 · link A to/with B + a link between...

This bridge links the town with the island. 这座桥把镇子和岛连起来。 There is a link between diet and health. 饮食与健康之间有联系。 网络语境：Click the link. 点击链接。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 链句游戏：上一句的尾词作为下一句的开头，句子须含本单元新词，含 link 者加分，断链者输；② 互批：各写3句含 a link between... 的句子，互查 between 后是否接 and；③ 全对后一起打卡。

📝 中考考点卡 · link

考点1　v. link A to/with B（连接A与B）；n. a link between A and B（A与B的联系）——介词搭配必考
考点2　between...and... 固定结构
易错　link /lɪŋk/ ≠ line /laɪn/；写作文用 in link? ✗，正确连接词是 in addition / besides

⚖️ 易混辨析卡 · 别再认错link
link ↔ line
形近义远：link 是“环环相扣的联系”，line 是拉直的“线；行”
linkn./v. 联系；连接：a link between two cities
linen. 线；行：draw a line / wait in line
🔥 火眼金睛：选词填空：The bridge ______ the island with the mainland.
桥起“连接”作用，用 link...with...；line 是“线；划线于”，不表连接。

📖 微型故事《A Letter Takes Ten Days》

班级和山区中学结成笔友班两周了，李一鸣的邮件石沉大海。他想放弃，英语课代表却说：“Maybe their internet link is just slow.”第三周，回信到了——薄薄一页手写的纸：学校每周才开一次机房，老师帮全班把邮件攒在一起发。李一鸣把那页纸夹进书里。原来有一种连接不用光缆：一封信在路上走十天，也能把两个世界拉得很近。A link is not about speed, but about wanting to reach someone. 连接的意义不在快，而在想抵达。

🧑‍🏫 自测提问卡：
• 细节题：Why did the reply take so long to arrive?
• 推断题：What does the story suggest about what a “link” really means?
• 迁移题（开放）：What is the strongest link in your life right now—a person, a habit, or a place? 用英语说明理由

🏛️ 词源故事

link 指铁链上的一“环”。它一般认为来自古诺尔斯语 hlenkr（链环）——维京人的锁子甲和船链把它带进英语。一环扣一环，才成链：所以 link 天生带着“彼此牵动”的意味。今天的 hyperlink（超链接）不过是给这个千年老词换了一件电子外衣——互联网最浪漫的地方，是把链环从铁变成了字节。
