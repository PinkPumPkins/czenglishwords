1️⃣ 五维拆解法

形·拼写full name 两词组合：full（完整）+ name（名字），语序和中文一样"全+名"
✏️ 三个格子分清：full name 全名 ≠ first name 名 ≠ last name 姓
音·发音/fʊl neɪm/ name 重读，full 稍轻，/l/ 轻轻带过
🎧 跟读：full name · What's your full name? · write your full name
意·释义全名——英语姓名 = first name（名）+ last name（姓）；中文姓名全称同理：李明 = 姓李 + 名明
用·句型① Peter's full name is Peter Brown. ② What's your full name? ③ Please write your full name here.
拓·同族first name 名 · last name 姓 · middle name 中间名（英美人可有）· given name = first name

📋 功能句总结 · 姓名三件套问答

问：What's your full name? / May I have your full name? 答：My full name is Chen Jie. Chen 是 last name，Jie 是 first name。 正式场合（报名/办卡/考试）一律用全名

👨‍👩‍👧 家长指导卡

家长配合：考试报名季是 full name 的实战课堂——让孩子独立填一次自己的英文信息表（Full name / First name / Last name），家长只核对不代填；顺带讲讲您自己名字的来历，孩子练英语，全家攒故事。

🤝 同桌互助卡 · 找一个搭子，互相监督完成

① 互填信息卡：两人各填一张全英文信息卡（Full name / First name / Last name / Country），交换互查顺序与拼写；② 顺序抢答：一方念一个英文名（如 Ella Miller），另一方3秒内答出姓和名，10轮记分；③ 满分者盖章，两人一起打卡。

📝 中考考点卡 · full name

考点1　姓名结构：first name 在前（名）+ last name 在后（姓）——与中文"姓在前"相反
考点2　问全名：What's your full name? May I have your full name?
易错　Peter Brown 中 Brown 是 last name 不是 first name；中文姓名直译拼音时姓仍是 last name（Chen Jie：Chen 是 last name）

⚖️ 易混辨析卡 · 别再认错full name
full name ↔ first name ↔ last name
一张信息卡的三个格子，别填串行
full name全名：Peter Brown
first name名：Peter
last name姓：Brown
🔥 火眼金睛：Peter Brown 的 last name 是？
英语姓名名在前、姓在后：Peter 是 first name（名），Brown 是 last name（姓）。

📖 微型故事《The Name on the Certificate》

市英语风采大赛的证书上，朱一凡的名字被印成了 "Yifan Zhu"——名在前，姓在后。奶奶皱眉："咱家姓朱，怎么跑到后头去了？" 班级分享时他解释：英语习惯 first name 在前、last name 在后，中文姓名换成拼音也入乡随俗。他还在黑板上写下："My full name is Zhu Yifan; on English papers, Yifan Zhu." 全班恍然大悟。他在周记里写：A name changes its seat between languages, but never changes its owner. 名字会在两种语言间换座位，主人却从不换人。

🧑‍🏫 自测提问卡：
• 细节题：How was the name printed on the certificate, and why?
• 推断题：Why did the grandma frown when she saw the name?
• 迁移题（开放）：How would you write YOUR full name on an English paper? 用英语解释一次姓名顺序

┌── 核心 ── full name 全名 = first name + last name ├── 顺序 ── 英文：名在前姓在后 · 中文：姓在前名在后 ├── 家族 ── first name 名 · last name 姓 · middle name 中间名 ├── 场景 ── 考试报名 · 办卡 · 签证表 └── 句型 ── What's your full name?

🏛️ 词源故事

name 出自古英语 nama，词根可追溯到原始印欧语 *h₃nómn̥（名字）——这个根在各大语系都有直系后代：拉丁语 nomen（名字）生出了 nominate（提名）、noun（名词）；希腊语 onoma 生出了 anonymous（匿名的，"没有名字"）和 synonym（同义词，"共同的名字"）；梵语 nāmán 也是亲戚。"名字"这个概念，全人类共用一个几千年前的词根——所以 name 值得写全。

📜 名言 & 谚语

"What's in a name? That which we call a rose by any other name would smell as sweet." — Shakespeare《Romeo and Juliet》(1597)（名字有什么关系？玫瑰换了名字，照样芬芳）

🎵 歌词里的name

🎵 Adele《Hello》(2015)："Hello, it's me"——一句自报家门式的开场白，把"我是谁"唱成世界金曲；自我介绍的第一步，正是报上 full name。（主题关联：问候·自我介绍）

⚡ 冷知识

🔤 英美人的 middle name 常用首字母缩写登场：马克·吐温的真名是 Samuel L. Clemens，那个 L. 是 Langhorne。美国还有个老传统——用母亲的娘家姓给儿子当 middle name，等于把两个家族都写进 full name 里。
